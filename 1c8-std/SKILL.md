# 1c8-std — стандарты разработки 1С 8.x

Три уровня: **свод** ниже — что соблюдать всегда; **выжимка** (`digest/`) — правила с
номерами пунктов оригинала; **статья** на its.1c.ru — формулировка. Выжимки написаны моделью и
сверены с оригиналом рецензентом; цитируй по статье.

## Как искать

```bash
python3 <навык>/std8.py show 783          # выжимка; --full — ссылка на статью
python3 <навык>/std8.py find транзакц запрос   # все слова, по началу слова
python3 <навык>/std8.py find --in "Соглашения" имя
python3 <навык>/std8.py list              # разделы; list "Раздел" — статьи, [упр, моб, обыч]
```
Коды: 0 нашлось, 1 ничего, 2 неверный вызов. `find` ищет по выжимкам; `show` первой строкой
печатает путь файла — выжимка открывается `Read`, фразу ищи `Grep` по `digest/`. Скобка у правила —
откуда оно: номер пункта статьи, `(текст)`, `(рис.)`, `(табл.)`. Применимость —
приставкой в «Сути»: `Только обычное приложение.`, `Интерфейс 8.2 (до «Такси»).` — не для
управляемых форм «Такси».

## Свод: что соблюдать всегда

**Имена.** Переменные, процедуры и параметры — терминами предметной области, слова без пробелов с
прописной (454, 647); односимвольное — только счётчик цикла (454); синоним метаданных заполняют
всегда (474); слов, от которых смысл не меняется, в именах метаданных нет (550).

**Модуль.** Разделы — области в порядке стандарта, пустых нет; экспортные только для своего объекта — не
в `ПрограммныйИнтерфейс` (455); программный интерфейс комментируют обязательно (453); один
оператор в строке, отступ табуляцией, строка свыше 120 знаков переносится (456); необязательные
параметры — после обязательных, ориентир — не больше семи (640); дублирование выносят в общие
модули (440); ключевые слова канонически, с `Истина`/`Ложь` не сравнивают (441); директивы
компиляции — только в модулях управляемых форм и команд (439); общий модуль — один из четырёх
контекстов: серверный без постфикса, `ВызовСервера`, `Клиент`, `КлиентСервер` (469).

**Запросы.** Ключевые слова заглавными, `КАК` перед псевдонимом, не в одну строку (437); полей «на
всякий случай» не выбирают (729); под каждое условие нужен индекс, чьи поля в начале и
подряд (652).

**Транзакции.** `НачатьТранзакцию` и `ЗафиксироватьТранзакцию`/`ОтменитьТранзакцию` — парные, в
одном методе, начало перед `Попытка`, отмена первой в `Исключение`; внутри — только неделимое по
бизнес-логике (783); режим блокировки — `Управляемый` (460); чтение, по итогам которого меняют
базу, — в транзакции с блокировкой до чтения (648).

**Клиент и сервер.** Лишних серверных вызовов на действие пользователя нет, из `ПриОткрытии` к
серверу не обращаются (487); в модуль с повторным использованием кладут часто запрашиваемое,
полученное не изменяют (724).

**Обработчики и ошибки.** `ПередЗаписью` — как правило, заполнение реквизитов и предпроверки (464),
`ПриЗаписи` — связанные данные, сам объект там не меняют (465), всё — после проверки
`ОбменДанными.Загрузка` (773); `Отказ` не сбрасывают в `Ложь`, отказывая — называют причину (686);
запись журнала регистрации — одно событие (498); исключения не перехватывают, кроме названных
стандартом случаев; `Попытка` — локально, перехваченное не прячут от администратора (499).

**Безопасность и права.** Угроза — все серверные процедуры, доступные с клиента, включая процедуры
форм с `&НаСервере` (678); `Выполнить` и `Вычислить` по вводу пользователя не дают (669); путь к
файлу не хранят в реквизитах формы (542); привилегированный режим включают перед действием и
снимают сразу, а не в начале экспортной процедуры (485); роли атомарные, на элементарные
функции (689; вне УП/УТ 11 — совет).

**Управляемое приложение.** Вызов дольше 8 секунд — фоновым заданием с индикатором (642);
`Режим использования модальности` — `Не использовать` (703).

**Локализация.** Строки пользователю — `НСтр` на самом литерале; имён объектов метаданных не
показывают (761).

**Метаданные.** Только штатные и документированные возможности платформы; необоснованных ошибок
проверки и неиспользуемых объектов нет (467); необязательную функциональность — функциональными
опциями (470).
