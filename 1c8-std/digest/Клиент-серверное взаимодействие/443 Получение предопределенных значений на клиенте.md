# Получение предопределенных значений на клиенте (#std443)

**Суть.** Менеджеры объектов в клиентском коде недоступны.

**Обязательно**
- В тонком и веб-клиенте ссылки на предопределённые элементы справочников, планов видов характеристик,
  планов счетов, планов видов расчёта, значения перечислений и системных перечислений, точки маршрута
  бизнес-процессов получать функцией глобального контекста `ПредопределенноеЗначение` (текст).

**Не надо**
- Свои механизмы кеширования предопределённых значений на клиенте: серверный вызов идёт только при
  первом обращении, результат кешируется сам (текст).

**Совет**
- С «Библиотекой стандартных подсистем» 2.1.4 и выше — `ПредопределенныйЭлемент` модулей
  `ОбщегоНазначения` и `ОбщегоНазначенияКлиент`: возвращает `Неопределено` для несуществующих
  элементов (текст).

См. также: 697 (предопределённые элементы), 487 (минимизация серверных вызовов).
