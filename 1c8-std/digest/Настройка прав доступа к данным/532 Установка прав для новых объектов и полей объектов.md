# Установка прав для новых объектов и полей объектов (#std532)

**Суть.** Методика прав не допускает ролей с доступом к полям объекта, но не к объекту.

**Обязательно**
- Флажок «Устанавливать права для новых объектов» — только у `ПолныеПрава` (1).
- У новой роли «Устанавливать права для реквизитов и табличных частей по умолчанию» установлен,
  «Независимые права подчиненных объектов» снят (2).
- Права только на поля объекта требуют заранее установить в роли «Независимые права подчиненных
  объектов» и снять «Устанавливать права для реквизитов и табличных частей по умолчанию»,
  очистив права на все реквизиты и табличные части (3).
- Новым объектам и полям существующих объектов настроить права в соответствующих ролях (4).
