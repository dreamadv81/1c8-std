# Ограничение на установку признака «Вызов сервера» у общих модулей (#std679)

**Суть.** Признак `Вызов сервера` открывает процедуры вызову с клиента.

**Обязательно**
- В таких модулях — только процедуры для вызова с клиента, гарантирующие лишь разрешённые пользователю
  действия и данные — окончательный результат расчёта, а не исходные (1).
- Прочие серверные процедуры — в модулях без `Вызов сервера`; внимания требуют привилегированный режим
  и признак `Привилегированный` (1).
- Обычные формы использовать только в обычном приложении (2.1).
- Конфигурации не для толстого клиента, управляемое приложение, снимают флажок `Толстый клиент (вариант
  клиент-сервер)` (2.2).

**Не надо**
- Ставить `Вызов сервера` всем модулям с признаком `Сервер` подряд (1).
- Создавать и получать объекты (`СправочникОбъект`, `ДокументОбъект`) в толстом клиенте, управляемое
  приложение: ни через `ТолстыйКлиентУправляемоеПриложение`, ни в обычных формах (2.1).

См. также: 678 (безопасность интерфейса сервера), 469 (правила создания общих модулей), 485 (привилегированный режим), 680 (поддержка толстого клиента).
