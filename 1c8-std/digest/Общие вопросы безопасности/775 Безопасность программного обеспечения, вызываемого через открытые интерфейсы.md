# Безопасность программного обеспечения, вызываемого через открытые интерфейсы (#std775)

**Суть.** Стороннее приложение, вызванное через открытые интерфейсы, способно выполнить свой код.

**Обязательно**
- При интеграции через открытые интерфейсы отключать исполнение произвольного кода средствами
  вызываемого приложения (1).
- Перед открытием документов Microsoft Word и Excel через COM запрещать макросы —
  `WordBasic.DisableAutoMacros(1)`, `AutomationSecurity = 3` (2).
- Если автозапуск макросов нужен, сделать формы настройки безопасности запуска макросов для
  клиентского и серверного кода с элементами «Запретить автоматический запуск», «Разрешить запуск
  подписанных макросов (рекомендуется)» (по умолчанию), «Разрешить запуск не подписанных макросов
  (опасно)»; клиентская форма доступна каждому, настройки — в разрезе пользователей и каждому только
  свои, серверная форма и настройки — только администратору; при открытии документов учитывать (3).

**Совет**
- Наличие подписи макросов проверять свойством `VBASigned` открытого документа: не подписан — закрыть
  документ и вызвать исключение (3.1, 3.2).
