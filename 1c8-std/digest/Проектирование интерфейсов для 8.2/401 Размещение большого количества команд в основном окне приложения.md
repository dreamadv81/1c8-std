# Размещение большого количества команд в основном окне приложения (#std401)

**Суть.** Интерфейс 8.2 (до «Такси»). Для большого числа команд — обычно отчётов — панель
действий не оптимальна.

**Обязательно**
- У самого «полноправного» пользователя команд, видимых по умолчанию в панели действий, — не
  более 6-9 (текст).

**Совет**
- Снять видимость по умолчанию у большинства команд отчётов подсистемы с вложенными, оставив её
  востребованным (текст).
- Настраивать видимость «по ролям», когда нужно (текст).
- Команды подсистемы верхнего уровня собрать в общей форме с именем подсистемы в названии
  («Все отчеты по зарплате») (текст).
- Команды формы — гиперссылками, подчинённые отчёты с отступом под главным, рядом поясняющие
  надписи (текст, рис.).
- Дать в форме «отсылку» к настройке панели действий: «Отчеты раздела также могут быть доступны
  через Панель действий. Для размещения в Панели действий отчетов "быстрого доступа"
  воспользуйтесь ее настройкой» (текст, рис.).
- Рядом разместить команды смежных областей — подобие «см. также» (текст, рис.).
- Завести общую команду (`ВсеОтчетыПоЗарплате`), код которой — открытие общей формы:
  `ОткрытьФорму("ОбщаяФорма.ВсеОтчетыПоЗарплате", , ПараметрыВыполненияКоманды.Источник, ПараметрыВыполненияКоманды.Уникальность, ПараметрыВыполненияКоманды.Окно)` (текст).
- Названием подчеркнуть охват всех отчётов; команду — в подсистему верхнего уровня и в группу
  панели навигации (текст).
