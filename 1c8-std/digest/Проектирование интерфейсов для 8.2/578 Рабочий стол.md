# Рабочий стол (#std578)

**Суть.** Интерфейс 8.2 (до «Такси»). Рабочий стол — обязательный раздел; содержимое
складывается из форм ролей пользователя.

**Обязательно**
- Рабочий стол вводит пользователя в курс дел: «Что нужно сделать сегодня?», «Что появилось
  нового?», «На что следует обратить внимание?», «Каково состояние важных для меня
  сведений?» (текст).
- Состав форм — от ролей конфигурации (текст).
- Разрабатывать особенно тщательно: его видят первым (текст).
- Формы делать существенно меньше обычных и давать богатые возможности (текст).
- Формы делать по умолчанию невидимыми, «с запасом» — под настройку (текст).
- У реального пользователя с учётом ролей — по умолчанию 3-6 форм (текст).
- В списках по умолчанию — не менее 3,5 строк (текст).
- Следить, чтобы панель действий не стала непонятной от разнородности команд из разных
  разделов (текст).

**Не надо**
- Перегружать формы стола (текст).
- На формах стола: списки с горизонтальной полосой прокрутки, меню «Все действия»; команду
  вызова справки — по возможности (текст).
- В командной панели списков — команды поиска и отмены поиска (текст).

**Совет**
- Командную панель стола допускается заполнять вручную, сняв «Автозаполнение» (текст).
- В командных панелях форм — минимально необходимый набор команд (текст).
- В командных панелях динамических списков — команда обновления (текст).
- Панель действий — только при достоверно частотных и неконтекстных командах (текст).
