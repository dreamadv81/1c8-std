# Окна на старте (#std586)

**Суть.** Интерфейс 8.2 (до «Такси»). Окно на старте должно отключаться.

**Обязательно**
- Содержание не обязательно для ознакомления — флаг «Показывать при открытии программы» по
  умолчанию возведён (текст).

**Совет**
- Флаг располагать под содержанием окна, над кнопкой «Закрыть» (текст, рис.).
