# Требования к изображениям (#std596)

**Суть.** Интерфейс 8.2 (до «Такси»). Требования к картинкам конфигурации.

**Обязательно**
- Метафоры — хорошо узнаваемые, в едином стиле; объекты — современные (текст).
- Близким в ряду иконкам — разные очертания (текст).
- Иконки — разные по начертанию и ведущим цветам (текст).
- Одинаковые углы, перспектива, тень во всех иконках (текст).
- Формат — PNG с 8-битным альфаканалом, а для поля HTML документа — с 1-битным: `png-8` либо
  `png-24` без альфа-канала (текст).
- Цвета — полностью прозрачные либо непрозрачные: 0% или 100% (текст).

**Не надо**
- Иконки, различимые только по цвету (текст).
- Альфа-канал у картинок больше 40000 точек: в веб-клиенте «Microsoft Internet Explorer 6.0»
  рисуются неверно; картинок-коллекций с меньшими элементами не касается (текст).

**Совет**
- 1-битный альфа-канал, когда возможен без потери качества: меньше конфигурация (текст).
- Удалять из заголовка PNG палитру и гамма-коррекцию (текст).
