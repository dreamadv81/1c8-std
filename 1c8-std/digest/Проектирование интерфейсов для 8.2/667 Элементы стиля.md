# Элементы стиля (#std667)

**Суть.** Интерфейс 8.2 (до «Такси»). Оформление по умолчанию задаёт платформа; выделить элемент
управления — задача элемента стиля, а не значения в самом элементе. Виды: Цвет (значение RGB),
Шрифт (вид, размер, начертание), Рамка (тип и ширина границ).

**Обязательно**
- Придерживаться умолчаний платформы в большинстве случаев (текст).
- Менять оформление элементами стиля, а не конкретными значениями в самих элементах
  управления (текст).
- Использовать элемент стиля всегда, когда требуется изменить оформление (Цвет, Шрифт, Рамку),
  установленное по умолчанию: `ЦветТекста` — «стиль: ИнформационнаяНадпись» (1, рис.).
- Создавать каждый элемент стиля для применения в конкретной ситуации; понадобился такой же цвет
  или шрифт в другой ситуации — завести для неё отдельный элемент стиля (3).
- Подбирать название так, чтобы в нём отразилось назначение элемента стиля:
  `ФонУправляющегоПоля` — фон поля, управляющего видимостью других полей,
  `ТекстНевыбраннойКартинки` — текст на картинке, пока она не выбрана (4).
- Вид элемента стиля указывать после названия — чтобы по первым буквам находить нужный элемент в
  списке: `ПросроченныеДанныеЦвет`, а не `ЦветПросроченныхДанных` (5).
- Указывать в названии только тот вид, который используется фактически: у элемента вида «Цвет» —
  `ВажнаяНадпись`, а не `ШрифтВажнойНадписи`, когда задан только `ЦветТекста`, а `Шрифт` оставлен
  «Авто» (5, рис.).
- Брать имена и значения элементов стиля вида «Цвет» из перечня стандарта: `ПросроченныеДанные`
  `178,34,34`, `ПояснениеОтсутствующейГиперссылки` `128,128,128`, `ТекстЗапрещеннойЯчейки`
  `192,192,192`, `ИтоговыеПоказателиДокументов` `22,39,121`, `ИтогиЖурналаЦвет` `100,100,100`,
  `ФонУправляющего поля` `255,232,179`, `ТекстНевыбраннойКартинкиЦвет` `220,220,220`,
  `НегативноеСобытие` `178,34,34`, `ПозитивноеСобытие` `0,128,0`, `НеактуальнаяИнформация`
  `255,200,200`, `Диаграмма` `70,130,180`, `Прогноз` `199,21,133`, `ПоясняющийТекст`
  `128,122,89` (табл.).
- Брать оттуда же элементы стиля вида «Шрифт»: `ОсновнойЭлементСписка`,
  `ОсновноеИтоговоеЗначение`, `ИтогиЖурналаШрифт` — обычный шрифт текста, начертание
  полужирный; `ТекстНевыбраннойКартинкиШрифт` — обычный шрифт текста, размер 12 (табл.).

**Не надо**
- Задавать оформление значением RGB или выбором цвета web/windows вместо элемента стиля:
  `ЦветТекста` «70, 130, 180» или «Синий со стальным оттенком» (1, рис.).
- Подменять элементом стиля оформление, которое платформа использует по умолчанию: у гиперссылки
  `ЦветТекста` оставляют «Авто», а не заводят свой элемент «стиль: Гиперссылка» с тем же
  цветом (2, рис.).

**Совет**
- Нескольким элементам стиля с одинаковым названием, но разным видом включать вид в название —
  слова «Цвет», «Шрифт», «Рамка»: `ТекстНевыбраннойКартинкиЦвет` и
  `ТекстНевыбраннойКартинкиШрифт` (5).
