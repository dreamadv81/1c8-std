# Содержание отчета (#std670)

**Суть.** Интерфейс 8.2 (до «Такси»). Показатели отчёта; контекстный отчёт запускают из панели
навигации объекта учёта, неконтекстный — из командного интерфейса.

**Обязательно**
- Состав показателей соответствует назначению отчёта — цели анализа (1.1).
- Включать только показатели, связанные общей целью анализа (1.2).
- Выводимые данные, помеченные на удаление, выделять явным образом (1.4).
- Учитывать, что показатель бывает в разных валютах (2.1).
- Для сравнительного анализа валюта показателя единая в отчёте (2.1).
- Показатель в разных валютах — и в исходной, и в единой валюте отчёта (2.2).
- В контекстных отчётах исключать из группировок объект анализа — контекст (3.3, рис.).
- При СКД имя контекстного варианта содержит слово «Контекст» (3.4).

**Не надо**
- Выводить в отчёт данные, помеченные на удаление (1.4).
- При вариантах отчёта — давать выбирать контекстные варианты в списке вариантов и в панели
  отчётов (3.2).

**Совет**
- Без СКД обеспечивать расшифровку всех выводимых показателей (1.3).

См. также: 676 (выделение помеченных на удаление).
