# Поля периодов (#std672)

**Суть.** Интерфейс 8.2 (до «Такси»). Умолчания именования и формата полей периодов в схеме
компоновки данных; настройки полей `ПериодСекунда` и `Регистратор` нужны для корректного
упорядочивания данных при расшифровке по регистратору.

**Обязательно**
- Пути полей периодов в схеме компоновки данных — `Периоды.Год`, `Периоды.Полугодие`,
  `Периоды.Квартал`, `Периоды.Месяц`, `Периоды.Декада`, `Периоды.Неделя`, `Периоды.День`,
  `Периоды.Час`, `Периоды.Минута`, `Периоды.Секунда`; синонимы — «Период, год», «Период,
  полугодие», «Период, квартал», «Период, месяц», «Период, декада», «Период, неделя», «Период,
  день», «Период, час», «Период, минута», «Период, секунда» (1, табл.).
- Форматные строки: у года `Л=ru; ДФ='yyyy "г."'` («2012 г.»), у полугодия
  `Л=ru; ДФ='ММ.гггг "г."'` («06.2012 г.»), у квартала
  `Л=ru; ДФ='к "квартал" гггг "г."'` («3 квартал 2012 г.»), у месяца
  `Л=ru; ДФ='MMMM гггг "г."'` («Август 2012 г.»), у декады, недели и дня
  `Л=ru; ДФ='dd.MM.yyyy "г."'` («03.08.2012 г.») (2, табл.).
- У поля `ПериодСекунда` установить ограничение на использование поля в качестве доступного поля
  выбора, отбора, группировки и упорядочивания: пользовательским это поле не является (3.1).
- У поля `Регистратор` указать выражение представления «Регистратор» (3.2).
- У поля `Регистратор` указать выражение упорядочивания «ПериодСекунда возр, Регистратор
  возр» (3.3).
