# Заголовок отчета (#std674)

**Суть.** Интерфейс 8.2 (до «Такси»). Заголовок отчёта и названия однотипных вариантов.

**Обязательно**
- Заголовок чётко отражает цель анализа и содержание отчёта (1).
- Заголовок узнаваемый и понятный (1).
- При вариантах заголовок каждого варианта всегда заполнен и соответствует наименованию
  варианта (2, рис.).
- Уточнение по группировке у однотипных вариантов — во множественном числе, без разделителей
  (тире, скобок и т.п.), слова названия согласованы: «Анализ расчетов с клиентами по договорам»,
  а не «Анализ расчетов с клиентами (по договорам)» (3, табл.).

**Не надо**
- Оставлять таблицу варианта без заголовка (2, рис.).
- Название «Основной» для варианта отчёта — запрещается: новичку не понятно, что за ним
  кроется (4).
- Употреблять слово «отчет» в синониме и заголовках отчётов (5).

**Совет**
- Давать вариантам осмысленные названия: «Анализ причин проигрыша сделок по партнерам» (4).
- Разделители и специальные знаки — в исключительных случаях, для стандартизованной отчётности (3).
- Несколько элементов — заголовок каждому; общий тогда не обязателен (6).
