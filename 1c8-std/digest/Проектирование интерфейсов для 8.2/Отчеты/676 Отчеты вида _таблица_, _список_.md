# Отчеты вида "таблица", "список" (#std676)

**Суть.** Интерфейс 8.2 (до «Такси»). Структура, сортировка и оформление отчёта.

**Обязательно**
- Отчёт максимально соответствует целям и задачам анализа: видно, для кого он («должность,
  роль пользователя») и на какие вопросы отвечает (1).
- Вложенность — не больше 3 уровней (1.1).
- Вложенность группировок — от общего к частному: «Номенклатура» внутри «Партнер» (1.2, рис.).
- Уточняющую свойства информацию — вместе с объектом анализа: «Характеристика» при
  «Номенклатура» (1.4, рис.).
- Информацию, которая сама объект анализа, но негруппируема или усложнит восприятие, —
  отдельной колонкой: «Валюта» рядом с «Партнер» (1.4, рис.).
- Показатели — в колонках, по важности слева направо; иногда по формуле: «Выручка»,
  «Себестоимость», «Доп. расходы», «Валовая прибыль», «Рентабельность, %» (1.5, рис.).
- Показатели — в строках при сравнении в динамике (1.5, рис.).
- Печать — макет оптимизировать под формат А4 (1.7).
- Сортировка по умолчанию — от назначения: наверху самое важное (2.1, рис.).
- По алфавиту (по возрастанию) — когда числа вторичны, а ищут по наименованию (2.2, рис.).
- По периоду (по возрастанию) — при анализе с учётом периода (2.3).
- Сортировать только по видимым группировкам или показателям (2.4).
- Принцип сортировки понятен без объяснений (2.4).
- Негативные факты — красным, `НегативноеСобытие` `RGB 178,34,34`; позитивные — зелёным,
  `ПозитивноеСобытие` `RGB 0,128,0`: «Рентабельность > 50%», «Рентабельность < 30%»
  (3.1, рис.).
- Фон неактуальных ячеек — розовый, `НеактуальнаяИнформация` `RGB 255,200,200` (3.2, рис.).
- Итоговая информация — жирным, `ИтоговаяИнформация` (3.3).
- Отрицательные значения выделять, если однозначно значат ошибку или негативный факт (3.4).
- Помеченные на удаление — зачёркнутым, `ПомеченныеНаУдалениеДанные` (3.5).
- Общие итоги отключать, когда бессмысленны (4).

**Не надо**
- Сортировать по алфавиту, когда сравнивают числа: долги сравнивать сложно (2.1, рис.).

**Совет**
- Группировку по периоду — в колонках, по возрастанию (1.3, рис.).
- В списках колонка с порядковым номером — первая (1.6).
