# Команда "Создать" в журналах документов (#std582)

**Суть.** Интерфейс 8.2 (до «Такси»). Когда «Создать» в журнале документов делают подменю.

**Обязательно**
- В подменю размещаются команды для открытия конкретных типов документов (2, рис.).
- Картинку «плюс» добавлять только для подменю «Создать» (3, рис.).

**Не надо**
- Ставить картинку каждой команде (3, рис.).

**Совет**
- Документы в некоторых журналах создавать подменю «Создать» вместо стандартной команды
  «Создать»; клавиша `Insert` открывает «Выбор типа документа» (1, 5).
- Подменю — когда видов документов немного (до 6) (1).
- …когда журнал часто используется в работе (1).
- Команды подменю сортировать по частоте использования, а не в алфавитном порядке (4).
