# Заголовки списков (#std607)

**Суть.** Интерфейс 8.2 (до «Такси»). Заголовок списка и количество.

**Обязательно**
- Список с командной панелью: заголовок — группой с рамкой «линия» (1.1, рис.).
- У списка без командной панели — в положении «верх» (1.2, рис.).
- Количество элементов показывать только где уместно и помогает решить задачу (2.1).
- Принятое у списка количество выводить во всех формах программы, где этот список используется
  и решает аналогичные задачи (2.2).
- Количество выводится после заголовка, в круглых скобках: «Товары (19)» (2.3, рис.).

**Не надо**
- Выводить количество в пустом списке: «Товары(0)» (2.4, рис.).
- Выводить заголовок, когда список на форме один: заголовок — название формы (3.1, рис.).
- …когда списков два одного контекста и назначение интуитивно понятно и не требует
  дополнительного пояснения (3.2, рис.).
- …когда список на странице (вкладке): заголовок — её название (3.3, рис.).

**Совет**
- В остальных случаях заголовок показывать (текст).
