# Групповые обработки в списках (#std653)

**Суть.** Интерфейс 8.2 (до «Такси»). Отклик групповой обработки — одинаковый на одинаковые
действия и обязательный.

**Обязательно**
- Сообщать пользователю о количестве удачно выполненных операций: «Для 4 из 4 выделенных в
  списке заказов клиентов установлен статус "Согласован"»; при ошибках — «Статус "К
  обеспечению" не установлен ни для одного заказа клиента.» (1, рис.).
- Если часть объектов групповой обработки или все они выполнены неудачно, сообщить об этом
  пользователю: например, причину по каждому документу — в панель «Сообщения» («Документу Заказ клиента
  ТДЦУ-000034 от 08.04.2011 15:24:50 уже присвоен статус "Закрыт"»), итог — оповещением
  «Статус "Закрыт" не установлен ни для одного заказа клиента.» (2, рис.).
- При выделении нескольких строк, в том числе строк группировки, строки группировок в момент
  групповой обработки игнорировать: обработка применяется только к выделенным строкам (3).
- При выделении только строки группировки и применении групповой обработки выдавать
  платформенное сообщение «"01.03.2010" - Действие недоступно для строки группировки
  списка!» (3, рис.).

**Не надо**
- Оставлять пользователя без отклика при возникновении ошибок (2).
