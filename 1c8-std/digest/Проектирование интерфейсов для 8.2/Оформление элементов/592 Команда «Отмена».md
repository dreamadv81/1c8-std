# Команда «Отмена» (#std592)

**Суть.** Интерфейс 8.2 (до «Такси»). Назначение команды «Отмена» и кнопка по умолчанию.

**Обязательно**
- «Отмена» — для реальной отмены установленных настроек, и она приводит к закрытию
  формы (текст).
- Никакие действия, кроме закрытия формы, недоступны — кнопкой по умолчанию должна быть
  «Закрыть» (текст).

**Не надо**
- «Отмена» кнопкой по умолчанию (текст).
