# Значения по умолчанию (#std594)

**Суть.** Интерфейс 8.2 (до «Такси»). Значение, подставляемое по умолчанию, выделяют и называют
«основным».

**Обязательно**
- Название команды выбирается по заголовку формы: «Использовать как основной», «Использовать
  как основную», «Использовать как основное» (текст).
- Элемент, выбранный основным, — шрифт `ОсновнойЭлементСписка`: шрифт диалогов и меню,
  начертание «жирный» (текст, рис.).
- Полей для заполнения по умолчанию несколько — оформлять группой с заголовком «Используются
  как основные» (текст, рис.).

**Не надо**
- Добавлять слово «основной» в заголовки полей такой группы (текст).

**Совет**
- Значения для подстановки по умолчанию выделять явно и называть термином «основной» (текст).
- Основной элемент списка выбирать отдельной командой командной панели списка (текст, рис.).
- Поле для заполнения по умолчанию одно — после заголовка добавлять «основной» («основная»,
  «основное») в круглых скобках: «Банковский счет (основной):» (текст, рис.).
- У создаваемой формы есть подчинённые формы — значения по умолчанию записывать автоматически,
  без сообщений пользователю (текст).
