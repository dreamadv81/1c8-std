# Гиперссылка на счет-фактуру (#std595)

**Суть.** Интерфейс 8.2 (до «Такси»). Как оформляют гиперссылку на счет-фактуру в форме
документа.

**Обязательно**
- Подвал многоколоночный и «счет-фактура» относится к колонке — гиперссылку по ширине
  колонки (текст).
- Гиперссылок несколько — размещать их друг под другом (текст, рис.).

**Не надо**
- Сообщение типа «Документ не записан. Записать?», когда для создания счета-фактуры
  требуется записать текущий объект: по возможности записывать его автоматически (текст).

**Совет**
- Гиперссылку размещать внизу формы до группы полей «Ответственный» и «Комментарий» (текст).
- Держать её отдельной строкой, выравнивая по левому краю формы (текст, рис.).
- Перед ссылкой — подпись «Счет-фактура»; тип допускается уточнять: «Счет-фактура
  выставленный», «Счет-фактура полученный», «Счет-фактура на сумму вознаграждения»
  (текст, рис.).
- Гиперссылку размещать на всю ширину формы (текст).
- Счет-фактура не указан — текст «Создать счет-фактуру» (текст, рис.).
- Счет-фактура указан — его номер и дата: «№ КФ00-000001 от 02.04.2011г.» (текст, рис.).
- Ввод счета-фактуры не требуется — текст «Не требуется» (текст, рис.).
- Прав на создание счета-фактуры нет, а на чтение есть — вместо гиперссылки надпись
  «\<Недостаточно прав для создания счета-фактуры>» в угловых скобках (текст, рис.).
- Текст этой надписи — цвет `ПояснениеОтсутствующейГиперссылки` `128,128,128` (текст).
