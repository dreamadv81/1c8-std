# Группировка команд (#std574)

**Суть.** Интерфейс 8.2 (до «Такси»). Группы команд в ПН.

**Обязательно**
- Много команд в группе «Обычное» — группировать по смыслу: пересмотреть содержимое
  подсистемы и разбить на подсистемы так, чтобы в группе было от 4 до 9 команд (текст).
- Состав команд — без полосы прокрутки в ПН по умолчанию (текст).
- Нечастотные команды скрывать: пользователь включит их сам (текст).
- Учитывать: по умолчанию все группы раскрыты (текст).

**Не надо**
- По возможности группы из одной команды: с учётом ролей группа может стать «вырожденной»
  для части пользователей (текст).
- Вложенность групп глубже 2: на втором уровне ширина текста команды — 36 символов (текст).
- Названия групп в ПН, пересекающиеся с системными группами, например «Создать», «Отчеты»,
  «Сервис», «См. также» (текст).
