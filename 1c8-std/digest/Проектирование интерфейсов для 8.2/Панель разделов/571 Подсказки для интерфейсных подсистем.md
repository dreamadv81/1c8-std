# Подсказки для интерфейсных подсистем (#std571)

**Суть.** Интерфейс 8.2 (до «Такси»). Подсказки и справка разделов ПР.

**Обязательно**
- Назначение раздела должно быть однозначно понятно из его названия: пользователь сразу
  понимает, где искать нужное (текст).

**Совет**
- Подсказки для ПР необязательны (текст).
- Подсказка может дополнительно расшифровывать содержимое раздела, например кратким
  перечислением входящих в него функций (текст).
- Справка для разделов ПР необязательна (текст).

См. также: 712 (панель разделов 8.3), 478 (подсказка и проверка заполнения).
