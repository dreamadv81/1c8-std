# Компоновка форм (#std597)

**Суть.** Интерфейс 8.2 (до «Такси»). Что и в каком порядке стоит в шапке формы документа.

**Обязательно**
- В шапке формы документа размещать реквизиты, нужные для правильной регистрации документа (1.2).
- Взаимозависимые поля располагать последовательно, одно под другим: «Подразделение» сразу
  под «Организация» (2.3).
- Под полем «Вид операции» размещать реквизиты, состав которых от него зависит, кроме отражаемых
  в содержательной части формы (2.4).
- Число и состав колонок определяются количеством реквизитов документа (1.3).

**Не надо**
- Указывать в шапке содержательные сведения документа, итоговые и второстепенные реквизиты (1.2).

**Совет**
- Один реквизит в разных формах — в одинаковом месте: «Контрагент» слева вверху всех форм,
  где он есть (1.1).
- Шапка может состоять из одной, двух или трёх колонок (1.3).
- В левой колонке — основные сведения, в правой — второстепенные (2.1).
- Левая колонка: «Важные для заполнения поля», «Поля, заполняемые пользователем», «Обязательные
  для заполнения поля», «Поля, значения которых заполняются по данным, приходящим извне» (2.1, табл.).
- Правая колонка: «Вспомогательные, малозначительные поля», «Поля, заполняемые автоматически,
  значение которых требуется только проконтролировать», «Не обязательные для заполнения поля»,
  «Поля, значения которых пользователь устанавливает самостоятельно по внутренним данным» (2.1, табл.).
- Порядок левой колонки: «Номер, дата», «Вид операции», «Контрагент», «Банковский счет
  (контрагента)», «Договор», «Контактное лицо» (2.2, табл.).
- Порядок правой колонки: «Организация», «Банковский счет (организации)», «Подразделение»,
  «Склад», «Касса», «Регистрация в ИФНС» (2.2, табл.).
- Например, «Номер» и дата («от») стоят в одной строке, «Вид операции» — под ними (3, рис.).
