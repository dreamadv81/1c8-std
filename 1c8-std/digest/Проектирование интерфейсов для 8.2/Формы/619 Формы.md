# Формы (#std619)

**Суть.** Интерфейс 8.2 (до «Такси»). Форма рассчитывается на клавиатурный ввод.

**Обязательно**
- Форма должна быть оптимизирована под клавиатурный ввод (текст).
- Сценарий переходов по клавише `Tab` — логичный (текст).
- Последний переход должен быть на кнопку, завершающую сценарий (текст).
- Связанные объекты располагать так, чтобы переходы по `Tab` шли последовательно (текст).

См. также: 597 (компоновка форм).
