# Ваимосвязанные поля (#std634)

**Суть.** Интерфейс 8.2 (до «Такси»). Взаимосвязанные поля — когда заполнение одного зависит от
значения, выбранного в другом.

**Обязательно**
- Пользователю визуально показывать, какое поле заполнять первым (текст).
- Зависимое поле оформлять недоступным, пока не заполнено основное — например, «Договор»
  недоступен, пока пуст «Контрагент» (текст, рис.).
