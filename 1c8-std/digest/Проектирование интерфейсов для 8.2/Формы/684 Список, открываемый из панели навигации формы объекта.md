# Список, открываемый из панели навигации формы объекта (#std684)

**Суть.** Интерфейс 8.2 (до «Такси»). Список из панели навигации формы объекта показывает данные
этого объекта.

**Обязательно**
- Список, открываемый из панели навигации формы объекта, отражать с отбором по этому объекту (1).

**Не надо**
- Выводить в списке название объекта надписью или полем ввода в режиме «просмотр»: оно уже в
  области системных команд и в панели навигации (2, рис.).
- Отражать колонку с названием объекта — для каждой строки оно одинаково (3, рис.).
- Указывать название объекта в названии команды панели навигации: «Банковские счета контрагента»
  вместо «Банковские счета», «Договоры контрагента» вместо «Договоры», «Ответственные лица
  организаций» вместо «Ответственные лица» (4, табл.).
