# Командные панели табличных частей (#std695)

**Суть.** Интерфейс 8.2 (до «Такси»). Команды табличной части формы объекта; форм списков
стандарт не касается.

**Обязательно**
- Команды, влияющие на заполнение отдельных строк, применять исключительно к выделенным
  строкам (1.1).
- Добавив такую команду, добавлять в подменю «Все действия» команду «Выделить все»: многие не
  знают `Ctrl+A` (1.2, рис.).
- Команды на строки, отобранные особым алгоритмом, а не выделенные, допускаются только для
  частотных операций, где выделить строки сложно (1.3).
- Схожие команды — одна на выделенные строки, другая на все: из названий должно быть понятно, на
  какие строки они влияют — «В строках с незаполненной ставкой», «В выделенных строках» (1.4, рис.).

**Не надо**
- Разводить одну команду на две — «Заполнить по виду цен во всех строках» и «Заполнить по виду
  цен в выделенных строках» вместо «Заполнить по виду цен» (1.1, рис.).

**Совет**
- Панель может содержать команды ко всей табличной части, к отдельным строкам и к одной
  строке (текст).

См. также: 653 (групповые обработки в списках), 694 (подменю).
