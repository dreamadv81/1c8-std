# Шрифты (#std687)

**Суть.** Шрифты — стилевые, с платформы 8.3.2.

**Обязательно**
- Использовать стилевые шрифты `<Шрифт текста>`, `<Мелкий шрифт текста>`,
  `<Крупный шрифт текста>`, `<Очень крупный шрифт текста>` (текст).

**Не надо**
- Прочие шрифты: могут поддерживаться не всеми операционными системами, где работает клиент
  1С:Предприятия (текст).

**Совет**
- При необходимости можно шрифты из состава MS Core Fonts: `Andale Mono`, `Arial`, `Arial Black`,
  `Comic Sans MS`, `Courier New`, `Georgia`, `Impact`, `Times New Roman`, `Trebuchet MS`,
  `Verdana`, `Webdings` (текст).
