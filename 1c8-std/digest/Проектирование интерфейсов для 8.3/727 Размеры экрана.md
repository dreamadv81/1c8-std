# Размеры экрана (#std727)

**Суть.** Формы — под 1280х668 пикселей.

**Обязательно**
- Типовое разрешение — 1280х768 пикселей, разработка в стандартном 96 DPI (1).
- Основное окно растянуто на весь экран, панель задач снизу отнимает 40 пикселей, браузер — в
  среднем 60 (Internet Explorer 54, Mozilla Firefox 63, Google Chrome 60) (2).
- Для работы — 1280х668 пикселей (3).
- Элементы форм при типовом разрешении — без вертикальной и горизонтальной полос прокрутки; в
  списках вертикальная допускается (4).

**Не надо**
- Горизонтальная полоса прокрутки в списках (4).

См. также: 566 (общие рекомендации).
