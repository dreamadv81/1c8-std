# Оформление групп разделов с настройками и справочниками (#std753)

**Суть.** Группы раздела свёртывают и умещают в экран; типовым разрешением экрана считается
1280x768 px, размеры даны с его учётом.

**Обязательно**
- Разделы из нескольких групп реализовать свертываемыми группами: `Поведение` «Свертываемая»,
  `ОтображениеУправления` «Картинка», `Отображение` «Обычное выделение», `ЦветТекстаЗаголовка`
  «Авто», `ШрифтЗаголовка` «Авто» — тогда заголовок отображается правильно (2, рис.).
- Сворачивать группы, по возможности избегая появления вертикальной прокрутки (2.1).
- Раздел из одной группы — развёрнутый, `Поведение` «Обычное», заголовок в такой группе не
  используется (3, рис.).

**Совет**
- Группа раздела может включать в себя заголовок, реквизиты и настройки, информационные
  сообщения (1, рис.).
- Формировать группы так, чтобы все они умещались на экране 1280х768 пикселей (2.1, рис.).
- Первую группу допускается оставить развёрнутой, если это не повлечёт «растягивания» формы за
  пределы типового разрешения 1280х768 пикселей (2.2, рис.).
