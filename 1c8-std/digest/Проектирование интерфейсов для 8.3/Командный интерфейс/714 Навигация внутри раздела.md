# Навигация внутри раздела (#std714)

**Суть.** Внутри раздела ходят «Панелью функций текущего раздела» либо областью команд
навигации и действий в составе «Меню функций»; группировать команды можно только во второй.

**Обязательно**
- Команды раздела должны решать задачу по конкретному участку работ или области
  деятельности (1.1).
- Группировать команды не по техническим признакам (вид объекта, действие при выборе), а по
  тому, как их структурирует пользователь (3.1).
- Название группы не должно пересекаться с названиями системных групп «Создать», «Отчеты»,
  «Сервис», «Важное», «См. также» (3.4).
- Группе из нескольких команд с одной важной заголовок обязателен (3.4, рис.).

**Не надо**
- Делать группы всего из одной команды (3.3, рис.).
- Делать группы, где важной выведена только одна команда, — запрещено (3.3, рис.).

**Совет**
- «Панель функций текущего раздела» использовать там, где команд в разделе немного, а при
  сложной структуре и большом количестве команд — скрывать (текст).
- Помещать в раздел команды перехода: списки и журналы документов, списки «первичных»
  документов, с которых начинаются бизнес-процессы, рабочие места, отчёты, специальные
  обработки, похожие на обычные списки (1.1).
- Второстепенные и подчинённые другим объекты можно не выносить в командный интерфейс (1.2).
- Выносить список, открываемый из разных документов и нужный без привязки к ним; не выносить
  открываемый из одного документа, малый и редко меняющийся (1.2, табл.).
- Следить, чтобы название команды не превышало 38 символов, а лучше умещалось в 30: иначе при
  стандартном разрешении экрана появляются полосы прокрутки (2.1).
- В одну группу включать не более 7 команд (3.2).
- Группам добавлять название (3.4).

См. также: 572 (панель навигации основного окна 8.2), 573 (названия команд 8.2), 623 (группа «Важное» 8.2), 574 (группировка команд 8.2), 601 (группа «См. также» 8.2), 575 (команды в панели навигации 8.2), 576 (панель действий 8.2).
