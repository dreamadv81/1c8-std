# Итоги в документах (#std718)

**Суть.** Итоги — полями ввода либо подвалом таблицы.

**Обязательно**
- Итоги — сразу под таблицей (или таблицами), по которым выводятся (1.1, рис.).
- В области итогов — только итоговые данные (1.2).
- Область итогов — по правому краю, не по левому (1.3, рис.).
- Фон итогов серый — элемент стиля `ИтогиФонГруппы`, `RGB 220,220,220` (1.4).
- Итоги — отдельными полями ввода с `ТолькоПросмотр` (1.5).
- Заголовки полей — без слова «итог» (1.6).
- Валюту (в случае отражения) — после поля ввода, у взаимосвязанных только после первого:
  «Всего», не «НДС (в т.ч.)» (1.7, рис.).
- Подвал — при итогах более чем по 4 колонкам одной табличной части, не умещающихся в
  строку (2.1).

**Не надо**
- Вставлять элементы между таблицей и итогами (1.1, рис.).
- Включать в группу итогов и выделять серым фоном не итоговые поля — «Остаток на начало»
  (1.2, рис.).

См. также: 613 (итоги в документах 8.2).
