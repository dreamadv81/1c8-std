# Переопределение общих модулей в условиях иерархии библиотек (#std554)

**Суть.** Методическая рекомендация: переопределяемый модуль базовой библиотеки на каждом уровне
иерархии не хранит реализацию, а лишь вызывает её — так обновление кода дешевле.

**Совет**
- Переопределяемый модуль объявлять в библиотеке нижнего уровня иерархии, самой базовой, по
  правилам создания общих модулей (1).
- В библиотеках более высокого уровня доопределять процедуры этого модуля, размещая в нём не сам
  код реализации, а только один вызов (2).
- В конечной конфигурации-потребителе модуль складывается из цепочки таких вызовов по уровням
  библиотек и собственных настроек (3).

**Пример**
```bsl
Процедура НастроитьИнтерфейс(Знач ПараметрыРаботы) Экспорт
  // Начало: Базовая библиотека
  МодульБазовойБиблиотеки.НастроитьИнтерфейс(ПараметрыРаботы);
  // Конец: Базовая библиотека
  // Начало: Библиотека второго уровня
  МодульБиблиотекиВторогоУровня.НастроитьИнтерфейс(ПараметрыРаботы);
  // Конец: Библиотека второго уровня
КонецПроцедуры
```
См. также: 553 (переопределяемые объекты), 469 (общие модули).
