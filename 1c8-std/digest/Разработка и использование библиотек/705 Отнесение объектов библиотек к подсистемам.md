# Отнесение объектов библиотек к подсистемам (#std705)

**Суть.** Библиотека собирается под одной корневой подсистемой.

**Обязательно**
- Все объекты библиотеки — в одной корневой подсистеме без командного интерфейса, у БСП это
  `СтандартныеПодсистемы` (1).

**Совет**
- Другие корневые подсистемы, с командным интерфейсом, допустимы (2).

См. также: 543 (подсистемы).
