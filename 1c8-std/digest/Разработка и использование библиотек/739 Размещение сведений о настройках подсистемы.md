# Размещение сведений о настройках подсистемы (#std739)

**Суть.** Общие настройки подсистемы — в переопределяемом модуле, специфичные для объекта — в
модуле его менеджера.

**Не надо**
- Определять список объектов подсистемы перебором объектов метаданных с конструкцией
  `Попытка … Исключение` (1.1).

**Совет**
- Общие для всех объектов подсистемы или их группы настройки задавать в переопределяемом модуле
  процедурой `ПриОпределенииНастроек` с параметром `Настройки` типа `Структура`, заполненным
  умолчаниями: новые свойства структуры расширяют интерфейс без нарушения совместимости (1).
- Список объектов, с которыми работает подсистема, перечислять отдельной процедурой
  переопределяемого модуля — `ПриОпределенииПодключенныхОтчетов` (1.1).
- Процедуры, переопределяющие бизнес-логику всех объектов подсистемы, тоже в переопределяемом
  модуле; имя — по действию, на каждое действие своя процедура (1.2).
- Настройки и обработчики отдельного объекта — в модуле менеджера объекта; процедуру о свойствах,
  реквизитах и наличии методов называть `ПриОпределенииНастроек<ИмяПодсистемы>`, на каждое
  действие заводить свою процедуру, а их наличие объявлять там же — это избавляет от
  `Попытка … Исключение` (2).

См. также: 551 (библиотеки), 553 (переопределяемые объекты), 644 (совместимость библиотек), 499 (перехват исключений).
