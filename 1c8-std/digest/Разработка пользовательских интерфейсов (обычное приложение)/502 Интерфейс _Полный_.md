# Интерфейс "Полный" (#std502)

**Суть.** Только обычное приложение. Доступ ко всем действиям.

**Обязательно**
- «Полный» отвечает функциональным возможностям конфигурации (1).
- Действия верхнего уровня группируются по крупным функциональным группам — одной или нескольким
  подсистемам: «Зарплата», «Бухгалтерия», «Производство» (2).
- «Операции» на верхнем уровне обязательны, если их нет в интерфейсе «Общий» (3).

**Не надо**
- Группировать подменю по прикладным объектам: «Справочники», «Документы», «Отчеты» и т. д. (4).
