# Стили (#std524)

**Суть.** Только обычное приложение. Стиль «Основной» и пять элементов стиля конфигурации.

**Обязательно**
- Конфигурацию оформляет стиль «Основной» — свойство «Основной стиль» объекта метаданных
  конфигурации; формам ставится стиль «Авто» (1).
- Кроме элементов стиля платформы `1С:Предприятие` используются пять элементов стиля
  конфигурации: цвет `ТекстИнформационнойНадписи`, цвет `ТекстПредупреждающейНадписи`, шрифт
  `ШрифтВажнойНадписи`, цвет `ТекстВторостепеннойНадписи`, цвет `ЦветГиперссылки` (2).
