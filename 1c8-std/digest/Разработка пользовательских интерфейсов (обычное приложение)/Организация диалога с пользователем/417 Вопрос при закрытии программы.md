# Вопрос при закрытии программы (#std417)

**Суть.** Только обычное приложение. Закрытие программы подтверждают вопросом.

**Обязательно**
- В конфигурации предусмотреть исключение случайного выхода из программы `1С:Предприятие` (текст).
- При выходе задавать пользователю вопрос «Завершить работу с программой?»: подтвердил —
  программа закрывается, отказался — продолжает работу (текст).
- Предусмотреть отключение вывода вопроса в персональных настройках пользователя (текст).
