# Имя элемента управления (#std503)

**Суть.** Только обычное приложение. Имя элемента даётся по его данным.

**Обязательно**
- У элемента с непустыми данными имя совпадает с ними (1).
- С пустыми данными и непустыми данными флажка — имя совпадает с данными флажка (2).
- Данные (данные флажка) указаны путём через точку — имя из их имени без точек (3).
- Данных и данных флажка нет или не указаны — имя из названия типа элемента управления и краткой
  расшифровки назначения, например `ПолеВыбораУсловияОтбора` (4).
- Совпали имена по правилу — один зовётся по нему, к именам остальных последовательно
  добавляется цифра начиная с «1»: `Номер`, `НадписьНомер`; `Номер1`, `НадписьНомер1`;
  `Номер2`, `НадписьНомер2` и т.д. (5).
