# Изменения размера колонки табличного поля (#std504)

**Суть.** Только обычное приложение. `ИзменениеРазмераКолонки` — по длине данных.

**Обязательно**
- Разрешать, когда длина представления данных заранее не известна или настолько велика, что
  ширину колонки по умолчанию ставят заведомо меньше требуемой, например «ссылочные значения,
  строки неограниченной длины и т.п.» (текст).
- Запрещать изменение размера, когда длина представления данных известна и может быть
  установлена при разработке формы, например «даты, числа, булевы значения» (текст).

**Не надо**
- Запрещать изменение размера колонке с иерархией — это исключение (текст).
