# Использование флагов "Автовыбор незаполненного" и "Автоотметка незаполненного" (#std507)

**Суть.** Только обычное приложение. Один флаг тянет за собой другой.

**Обязательно**
- Поле ввода с флагом «Автоотметка незаполненного» получает флаг «Автовыбор незаполненного» (текст).
- Свойство «Режим выбора незаполненного» при этом ставится в «При нажатии Enter» (текст).
- Правило равно для элементов формы и колонок табличного поля (текст).

**Совет**
- У полей ввода числа и даты — исключение: «Автовыбор незаполненного» по логике работы (текст).
