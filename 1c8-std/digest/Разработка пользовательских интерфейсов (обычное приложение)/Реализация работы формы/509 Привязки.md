# Привязки (#std509)

**Суть.** Только обычное приложение. Растягивание формы и привязки у разделителей.

**Обязательно**
- Ручную установку привязок минимизировать (текст).
- По горизонтали размеров не меняют «надписи, за исключением "информационных надписей" и
  надписей с гиперссылкой, флажки, переключатели, кнопки» и поля ввода, в которых значение
  заранее известной длины полностью видно, например код элемента справочника (текст).
- По горизонтали размер меняют «поля ввода, кроме случаев, когда они не изменяют размер,
  "информационные надписи", надписи с гиперссылкой, табличные поля, поля списка, полосы
  регулирования, командные панели, панели, рамки групп, индикаторы, поля HTML документов,
  диаграммы, диаграммы Ганта, дендрограммы, сводные диаграммы, поля картинок, поля табличных
  документов, поля текстовых документов» (текст).
- По вертикали размеров не меняют «надписи, поля ввода, кроме полей с многострочным вводом,
  флажки, переключатели, кнопки» (текст).
- По вертикали размер меняют «поля ввода с многострочным вводом, табличные поля, поля списка,
  панели, рамки групп, поля HTML документов, диаграммы, диаграммы Ганта, дендрограммы, сводные
  диаграммы, поля картинок, поля табличных документов, поля текстовых документов» (текст).
- Один элемент в «строке» или «столбце» диалога растягивается вместе с формой, несколько —
  пропорционально размеру формы (текст).
- При двух колонках, левой и правой, правая граница левой колонки меняет размер пропорционально
  размеру формы (текст).
- Слева и сверху от разделителя элементы привязываются к его границе как к правому и нижнему
  краю формы, справа и снизу — как к левому и верхнему; так же внутри панели (текст).
