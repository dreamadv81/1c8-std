# Порядок обхода элементов диалога (#std512)

**Суть.** Только обычное приложение. Порядок обхода.

**Обязательно**
- «Автопорядок обхода» — всем формам, кроме исключительных случаев, когда он нарушает логику
  работы с формой (текст).
- Обход сверху вниз, слева направо (текст).
- Обход с произвольного элемента — признак «Активизировать по умолчанию» (текст).
- Группа переключателей, флажков, элементов в рамке либо с надписью — один элемент обхода:
  сначала её элементы, потом следующий за группой (текст).
