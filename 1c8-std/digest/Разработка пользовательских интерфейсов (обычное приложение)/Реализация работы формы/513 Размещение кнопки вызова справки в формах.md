# Размещение кнопки вызова справки в формах (#std513)

**Суть.** Только обычное приложение. Кнопка справки.

**Обязательно**
- Кнопку справки — в верхнюю командную панель формы (текст).
- Нет верхней — кнопку в основную или самую используемую панель (текст).
- При выравнивании кнопок «Лево» кнопка справки — по возможности крайняя справа (текст).
- При другом выравнивании или вне панели решают по лучшей эргономике (текст).

**Совет**
- Допустима кнопка вызова помощи отдельно в форме, вне командной панели (текст).
