# Отображение единственного табличного поля в форме (#std514)

**Суть.** Только обычное приложение. Единственное табличное поле подписывают рамкой группы.

**Обязательно**
- Единственному табличному полю дополнительно ставить рамку группы с названием данных (текст).
- Рамка группы — над командной панелью табличного поля, без отступа (текст).
- Рамке группы ставится рамка «Подчеркивание» (текст).
- Текст рамки осмыслен и понятен: «Основные средства» для табличной части «ОС» (текст).
