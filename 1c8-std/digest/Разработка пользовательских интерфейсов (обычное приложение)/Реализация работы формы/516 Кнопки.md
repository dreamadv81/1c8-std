# Кнопки (#std516)

**Суть.** Только обычное приложение. Кнопки формы.

**Обязательно**
- Кнопки размещаются вне командных панелей (текст).
- Минимальный размер кнопки `60х19`, ширина растёт по заголовку (текст).
- Надпись на кнопке — одна строка (текст).

**Совет**
- Частотные кнопки (часто употребимые действия) оформлять текстом вместе с картинкой (текст, рис.).
- Иконку кнопки использовать и в строке табличной части для опознания типа данных
  команды (текст, рис.).
