# Программное управление видимостью страниц (#std518)

**Суть.** Только обычное приложение. Форма не должна остаться без видимой страницы: иначе
перестают срабатывать привязки элементов управления.

**Обязательно**
- В любой момент времени видима хотя бы одна страница (текст).
- Сначала включать все видимые страницы и только затем выключать все невидимые (текст).
