# Ограничение выполнения действий, доступных только при определенных условиях (#std520)

**Суть.** Только обычное приложение. Кнопку условно доступного действия не гасят: условие
проверяет обработчик нажатия.

**Обязательно**
- Нажатие на кнопку доступно в любом случае, даже когда само действие доступно только при
  определённых условиях (текст).
- Проверку, может ли пользователь выполнить действие, вести прямо в обработчике события нажатия
  на кнопку (текст).
- Действие доступно — выполнять; нет — коротко и понятно объяснить пользователю причину,
  например «Перед записью в элементе справочника "Номенклатура" необходимо заполнить реквизит
  "базовая единица"!» (текст).
