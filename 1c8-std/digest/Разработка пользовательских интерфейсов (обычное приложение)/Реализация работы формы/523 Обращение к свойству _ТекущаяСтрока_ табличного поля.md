# Обращение к свойству "ТекущаяСтрока" табличного поля (#std523)

**Суть.** Только обычное приложение. `ТекущаяСтрока` — не источник значений полей строки.

**Обязательно**
- Значения полей строки табличного поля получать через `ТекущиеДанные` или `ДанныеСтроки` (текст).
- У динамического списка нужные колонки явно добавлять в источник данных табличного поля перед
  открытием формы: обращение через `ТекущиеДанные` зависит от видимости колонок в списке;
  системных полей динамических списков и расширений табличного поля (`ПометкаУдаления`,
  `ЭтоГруппа`, `Дата` и т.д.) это не касается — они всегда доступны (текст).

**Не надо**
- Получать значения полей строки табличного поля свойством `ТекущаяСтрока` (текст).

**Пример**
```bsl
ИнформационнаяНадписьАдрес = "Адрес: " + Элемент.ТекущиеДанные.Адрес;
// колонку добавляют в источник данных до открытия формы
СправочникСписок.Колонки.Добавить("Адрес");
```
