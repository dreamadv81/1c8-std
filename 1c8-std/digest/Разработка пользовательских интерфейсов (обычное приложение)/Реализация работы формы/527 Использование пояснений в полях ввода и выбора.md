# Использование пояснений в полях ввода и выбора (#std527)

**Суть.** Только обычное приложение. Пустое поле поясняет, что в нём будет по умолчанию.

**Совет**
- В незаполненном поле ввода или выбора показывать значение по умолчанию либо трактовку пустого
  значения (текст).
- Пояснение писать в угловых скобках: «<Все поля>», «<Без условия>» (рис.).
- Пояснение снимать, когда поле активизировано для ввода (рис.).
