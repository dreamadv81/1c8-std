# Особенности размещения в командных панелях пунктов меню, не предназначенные для решения основных задач (#std528)

**Суть.** Только обычное приложение. Служебные команды собирают в отдельное подменю.

**Совет**
- Пункты меню, не решающие основных задач, а исполняющие команды специализированных целей либо
  особой группы пользователей, помещать в подменю (текст).
- Подменю называть по назначению и ставить правее основных команд панели — например
  «Администрирование» с «Сохранить отчет и основную настройку», «Редактировать описание
  отчета...», «Редактировать схему компоновки данных» (рис.).
