# Пользовательские представления объектов (#std468)

**Суть.** Чем заполняют свойства пользовательского представления объекта.

**Обязательно**
- `Синоним` заполняется обязательно, осмысленно и лаконично описывая объект (1).
- `Представление объекта`, у регистра `представление записи`, — лаконичное понятное название в
  единственном числе; заполняют, если синоним им быть не может (2).
- `Представление списка` — лаконичное понятное название во множественном числе либо
  самостоятельный термин; заполняют, если синоним им быть не может (4).
- Расширенные представления заполняют, когда короткое свойство, а при пустом — синоним, менее
  информативно (3, 5, 6).
- `Расширенное представление объекта`, у регистра `расширенное представление записи`, — полное
  название в единственном числе (3).
- `Расширенное представление списка` — полное название списка (5).
- `Расширенное представление` — полное название объекта метаданных (6).
- `Пояснение` — назначение объекта законченными предложениями; заполняют при неточном
  представлении (7).
- `Картинка` — подсистемам верхнего уровня с флажком «Включать в командный интерфейс»,
  32 на 32 (8).

**Совет**
- Синоним отражает действие — представление списка можно не указывать либо начать с
  «Документы» (4).
