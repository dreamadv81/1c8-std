# Длительные операции на сервере (#std642)

**Суть.** Серверный вызов дольше 8 секунд отдают фоновому заданию, показывая пользователю
индикатор.

**Обязательно**
- Все серверные вызовы, которые в обычных сценариях работы пользователя могут выполняться более
  8 секунд, выполнять асинхронно, фоновым заданием; длительных вызовов из клиентского кода в
  серверный избегать (1).
- Код длительной обработки располагать в модуле менеджера объекта или в общем модуле, результат —
  во временное хранилище; фоновые задания работают только с общими модулями, поэтому к менеджеру
  обращаться процедурой-обёрткой через `ОбщегоНазначения.ВыполнитьМетодКонфигурации` (2.1).
- Ожидать завершения задания 0.8 сек; не завершилось — вернуть управление на клиент и подключить
  обработчик ожидания: интервал опроса от 1 до 15 секунд с фиксированным коэффициентом 1.4 (2.1).
- На время операции показывать индикатор: у отчётов — в поле табличного документа свойством
  `ОтображениеСостояния` («Отчет формируется…»), иначе — блокирующей формой `РежимОткрытияОкна` =
  `БлокироватьОкноВладельца` с анимированной картинкой («Пожалуйста, подождите…») и кнопкой
  «Отмена» (2.1, рис.).
- Получив сведения о завершении задания, загружать результат из временного хранилища и
  обрабатывать (2.1).
- Асинхронное формирование требуется только для отчётов без СКД либо с СКД, но с
  переопределённой процедурой формирования — переопределён обработчик «Сформировать» либо в
  `ПриКомпоновкеРезультата` ставится `СтандартнаяОбработка` = `Ложь`, — и формирование которых,
  как правило, длительное (2.2).
- Поведение таких отчётов делать максимально похожим на отчёты СКД: настройки меняют и отчёт
  переформировывают, не дожидаясь окончания; при закрытии формы формирование прерывается (2.2).
- В алгоритмах, запускающих фоновые задания или пишущих данные информационной базы без участия
  пользователя, проверять, что в сеансе не установлен монопольный режим, и блокировать такие
  действия — в том числе там, где объекты записываются программно (4).
- Длительной операции с монопольным режимом сначала устанавливать режим, затем запускать фоновое
  задание — оно унаследует его от пользовательского сеанса — и на это время блокировать весь
  интерфейс приложения формой ожидания с `РежимОткрытияОкна` = `БлокироватьВесьИнтерфейс` (5).

**Не надо**
- Блокировать форму отчёта на время его формирования (2.2).
- Размещать на форме ожидания элементы управления, способные запустить фоновые задания: поля
  ввода, динамические списки, отчёты (5).

**Совет**
- С «Библиотекой стандартных подсистем» пользоваться общими модулями `ДлительныеОперации`,
  `ДлительныеОперацииКлиент` и процедурой `УстановитьСостояниеПоляТабличногоДокумента` модуля
  `ОбщегоНазначенияКлиентСервер` (3).
- Очищать временное хранилище сразу после получения результата: иначе при многократном выполнении
  операции хранилища накапливаются (3.1).
- Когда результат нужен несколько серверных вызовов, передавать фиксированный адрес заранее
  инициализированного хранилища (3.1).

**Пример**
```bsl
&НаКлиенте
Процедура НастроитьПараметрыПодключенияАвтоматически()
  ДлительнаяОперация = НачатьПоискНастроекУчетнойЗаписи(); // 1. Запуск фонового задания на сервере.
  // 2. Подключение обработчика завершения фонового задания.
  ПараметрыОжидания = ДлительныеОперацииКлиент.ПараметрыОжидания(ЭтотОбъект);
  Оповещение = Новый ОписаниеОповещения("ПриЗавершенииПоискаНастроек", ЭтотОбъект);
  ДлительныеОперацииКлиент.ОжидатьЗавершение(ДлительнаяОперация, Оповещение, ПараметрыОжидания);
КонецПроцедуры
&НаСервере
Функция НачатьПоискНастроекУчетнойЗаписи()
  ПараметрыВыполнения = ДлительныеОперации.ПараметрыВыполненияФункции(УникальныйИдентификатор);
  Возврат ДлительныеОперации.ВыполнитьФункцию(ПараметрыВыполнения,
    "Справочники.УчетныеЗаписиЭлектроннойПочты.ОпределитьНастройкиУчетнойЗаписи", АдресЭлектроннойПочты, Пароль);
КонецФункции
&НаКлиенте
Процедура ПриЗавершенииПоискаНастроек(Результат, ДополнительныеПараметры) Экспорт // 3. Обработка результата.
  Если Результат = Неопределено Тогда // Пользователь отменил задание.
    Возврат;
  КонецЕсли;
  Если Результат.Статус = "Ошибка" Тогда
    СтандартныеПодсистемыКлиент.ВывестиИнформациюОбОшибке(Результат.ИнформацияОбОшибке);
    Возврат;
  КонецЕсли;
  Настройки = ПолучитьИзВременногоХранилища(Результат.АдресРезультата);
  УдалитьИзВременногоХранилища(Результат.АдресРезультата);
КонецПроцедуры
```
