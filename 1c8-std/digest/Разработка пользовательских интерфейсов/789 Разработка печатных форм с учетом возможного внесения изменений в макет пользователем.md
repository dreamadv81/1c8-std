# Разработка печатных форм с учетом возможного внесения изменений в макет пользователем (#std789)

**Суть.** Пользователь правит макеты — параметры и области исчезают.

**Обязательно**
- При компоновке подсистемой «Печать» «Библиотеки стандартных подсистем» по макету СКД сохранять
  состав полей в макетах `ДанныеПечати` (1).
- При программной компоновке повышать устойчивость кода к изменениям в макете (2).
- Перед получением области проверять её существование `Макет.Области.Найти` (2.1).
- Вместо явного присвоения параметров в областях печати — `ЗаполнитьЗначенияСвойств` либо
  `Заполнить` коллекции `ПараметрыМакетаТекстовогоДокумента` (2.2).
- Обязательное изменение макета: при обновлении отключить пользовательский макет, оповестив
  пользователя; в БСП — `ОтключитьПользовательскийМакет`, `ПоставляемыйМакетИзменен`,
  `ИспользуетсяПользовательскийМакет` модуля `УправлениеПечатью` (3).
- Необязательное изменение: новый код обязан выводить форму и со старым макетом (3).

**Не надо**
- Переименовывать или удалять поля макета `ДанныеПечати`; расширять состав допускается (1.1).
- Переименовывать реквизиты или табличные части объекта без макета `ДанныеПечати`: сначала
  создать его, зафиксировав состав полей (1.2).
