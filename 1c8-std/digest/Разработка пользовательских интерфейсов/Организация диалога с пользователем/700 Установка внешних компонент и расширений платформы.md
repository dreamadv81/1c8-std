# Установка внешних компонент и расширений платформы (#std700)

**Суть.** Компоненты и расширения ставят по решению пользователя.

**Обязательно**
- Установка компонент и расширений — интерактивная: решение принимает сам пользователь (1.1).
- В диалоге установки указывать, для чего нужна компонента (расширение) и что не будет работать,
  если её не устанавливать (1.1).
- Вопрос задавать в явном виде: «Для продолжения работы требуется установить внешнюю компоненту,
  которая позволит работать с отчетностью. Для установки компоненты нажмите "Установить". После
  завершения установки нажмите "Продолжить".» (1.1).
- С «Библиотекой стандартных подсистем» предложение об установке расширения работы с файлами
  выводят процедуры общего модуля `ФайловаяСистемаКлиент`: `ВыбратьКаталог` — вместо метода
  `Показать` объекта `ДиалогВыбораФайла` с режимом работы `ВыборКаталога`; `ЗагрузитьФайл` —
  вместо `ПоместитьФайл`, `НачатьПомещениеФайла`, `Показать` с `Открытие`; `ЗагрузитьФайлы` —
  вместо `ПоместитьФайлы`, `НачатьПомещениеФайлов`, `Показать` с `Открытие`; `ОткрытьФайл` —
  вместо `ЗапуститьПриложение`; `СохранитьФайл` — вместо `ПолучитьФайл`, `Показать` с
  `Сохранение`; `СохранитьФайлы` — вместо `ПолучитьФайлы`, `НачатьПолучениеФайлов`, `Показать` с
  `Сохранение`; в остальных случаях — `ПодключитьРасширениеДляРаботыСФайлами` (1.3).
- Давать функции установки в любой момент работы — отдельным действием из формы персональных или
  административных настроек (2).

**Не надо**
- Молча — `УстановитьВнешнююКомпоненту` следом за неудачным `ПодключитьВнешнююКомпоненту` (1.1).

**Совет**
- Предложение об установке выводить перед прикладным действием: команда — проверка — сообщение с
  кнопкой установки — кнопка продолжения (1.2).
- В веб-клиенте спрашивать, только пока расширение не установлено; отказ не прерывает работу:
  вместо `НачатьПомещениеФайлов` — `НачатьПомещениеФайла` (1.2, рис.).
- Диалог БСП: «Для удобной работы с файловыми функциями предлагается установить расширение работы
  с файлами. Установить?», ответы — «Установить и продолжить», «Продолжить без установки»,
  «Больше не напоминать» (1.3, рис.).
