# Запрет редактирования полей таблицы по условию (#std399)

**Суть.** Вся статья — методическая рекомендация: приём, которым пользователя предупреждают, что
ввод данных в поле таблицы управляемой формы не имеет смысла или невозможен до заполнения других
полей.

**Совет**
- Для предупреждения пользователя применять свойства поля `ОтображениеПредупрежденияПриРедактировании`
  и `ПредупреждениеПриРедактировании` (текст).
- Текст предупреждения указывать в свойстве поля формы при разработке формы в конфигураторе (текст).
- Свойством `ОтображениеПредупрежденияПриРедактировании` управлять из встроенного языка при
  активизации строки таблицы и при изменении тех значений, которые влияют на условие редактирования
  поля (текст).
- Дать пользователю возможность редактирования уже введённого значения, даже если оно введено «не
  по правилам», чтобы он мог его удалить (текст).
- Когда от условий зависит и сам текст предупреждения, управлять из встроенного языка и свойством
  `ПредупреждениеПриРедактировании` (текст).
