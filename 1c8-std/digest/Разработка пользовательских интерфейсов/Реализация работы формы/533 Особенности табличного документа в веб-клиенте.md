# Особенности табличного документа в веб-клиенте (#std533)

**Суть.** Вся статья — рекомендация о табличном документе в веб-клиенте.

**Не надо**
- Обновлять состояние кнопок по текущей области документа: лучше сообщать при нажатии, почему
  действие недоступно (1.1).

**Совет**
- Перерасчёт формы после изменения ячейки вести на клиенте, не обращаясь на сервер, и «точечно»
  обновлять только зависимые ячейки (1.1).
- Нужен серверный вызов при завершении редактирования ячейки — сделать его единственным и по
  возможности `&НаСервереБезКонтекста` (1.2).
- Избегать в макетах множества колонок и объединений, применяя переменную ширину колонок для
  разных строк (1.3).
- В `Microsoft Internet Explorer 6.0` и `7` объединённым ячейкам с рамкой слева указывать рамку
  снизу (2).
- Ячейке с выравниванием по правому краю ставить `Размещение` = `Забивать`, когда часть
  содержимого бессмысленна, иначе `Обрезать` (3).

См. также: 487 (минимизация серверных вызовов).
