# Обращение из кода к автоматически формируемым элементам управления формы (#std536)

**Суть.** Платформа пересоздаёт сформированные ею элементы.

**Обязательно**
- Ставя их свойства программно, учитывать: после изменения `ОсновнаяТаблица` динамического списка
  командная панель перезаполняется, изменения свойств кнопок теряются и установку
  повторяют (текст).

**Не надо**
- Управлять из кода элементами формы, которые формирует платформа (текст).

См. также: 545 (пользовательские элементы управления формы).
