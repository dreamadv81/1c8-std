# Команды по модификации объектов (#std537)

**Суть.** Без признака `Изменяет данные` команде не достанется ни `Только просмотр` от формы, ни
автоматической блокировки объекта для редактирования.

**Обязательно**
- Свойство `Изменяет данные` устанавливать в `Истина` для всех команд, которые изменяют или могут
  изменять данные объекта (текст).
- Соблюдать правило и для команд, которые в некоторых сценариях данных не изменяют: команде
  заполнения табличной части, спрашивающей «Перед выполнением операции табличная часть будет
  очищена. Продолжить?», признак нужен в целом (текст).
