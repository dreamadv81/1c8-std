# Использование объекта ДанныеФормыКоллекция (#std628)

**Суть.** Данные объекта `ДанныеФормыКоллекция` едут с сервера на клиент порциями по мере
обращения к ним на клиенте, и неосторожный код формы порождает лишние неявные серверные вызовы.

**Обязательно**
- Учитывать эту особенность при разработке форм: новые порции данных передаются с сервера на
  клиент только по мере обращения к этим данным на клиенте (1).
- Обход строк коллекции, которая, как предполагается, может содержать большое количество строк
  (ориентир — от 20 строк), производить на сервере (2).
- Функцию `НайтиСтроки` у такой коллекции вызывать только на сервере (2).

См. также: 487 (минимизация серверных вызовов).
