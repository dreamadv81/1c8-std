# Ограничение на использование модальных окон и синхронных вызовов (#std703)

**Суть.** Платформа 8.3 и выше: модальность запрещена.

**Обязательно**
- Свойству `Режим использования модальности` ставить `Не использовать`, модальные методы
  заменять немодальными с блокированием окна владельца или всего интерфейса (2).
- Есть асинхронные вызовы в `ПередЗавершениемРаботыСистемы` модуля управляемого приложения —
  ставить `Отказ` = `Истина` и завершать работу системы из процедуры оповещения (4).

**Не надо**
- Использовать модальные формы и диалоги в конфигурациях для веб-клиента: запрещено (1).
- Использовать асинхронные вызовы в `ПриЗавершенииРаботыСистемы` модуля управляемого приложения:
  недопустимо (3).

**Совет**
- При переработке синхронных вызовов включать флажок «Поиск использования синхронных вызовов при
  проверке конфигурации», вручную исключая корректные вызовы вне веб-клиента (5).

См. также: 467 (общие требования к конфигурации).
