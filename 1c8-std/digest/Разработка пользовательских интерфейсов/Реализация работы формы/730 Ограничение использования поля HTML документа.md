# Ограничение использования поля HTML документа (#std730)

**Суть.** Поле с HTML-документом — крайнее средство.

**Обязательно**
- При разработке форм стремиться применять только штатные элементы управления платформы (1).
- Взяв поле с HTML-документом — допустимо для инструкций, справки, путеводителей только для
  просмотра, — самостоятельно обеспечить корректное отображение во всех клиентах и браузерах (2).

**Не надо**
- Использовать поля с `ВидПоля` = `ВидПоляФормы.ПолеHTMLДокумента`, когда возможны элементы
  управления платформы: вместо гиперссылок — кнопки, надписи с гиперссылками или
  форматированными строками (1).

См. также: 723 (разработка для Linux и macOS).
