# Открытие параметризированных форм (#std741)

**Суть.** Параметризированную форму основной не назначают; параметры объявляют явно.

**Обязательно**
- Нет других форм на роль основной — сделать основной параметризированную, а в
  `ПриСозданииНаСервере` проверять параметры и при незаполненных вызывать исключение (2).
- Текст исключения указывает причину, по которой форма не открывается (2).
- Параметры формы объявлять явно на закладке «Параметры»: тогда в `ПриСозданииНаСервере` не нужно
  проверять свойства структуры `Параметры` (3).

**Не надо**
- Назначать основной формой объекта ту, что требует параметризации, открывается только из
  встроенного языка и недоступна из меню «Все функции» (1).
