# История выбора при вводе (#std744)

**Суть.** `История выбора` — `Авто`; отключив её, чинят кнопки полей ввода.

**Обязательно**
- Свойству `История выбора` большинства объектов метаданных устанавливать значение `Авто` (1).
- Отключив историю выбора у объекта, во всех ссылающихся на него полях ввода ставить
  `КнопкаВыпадающегоСписка` — `Нет`, `КнопкаВыбора` — `Да`,
  `ОтображениеКнопкиВыбора` — `В поле ввода`: иначе перед выбором показывается меню
  с «Показать все» (2.2, рис.).

**Совет**
- Отключать историю выбора, когда она не соответствует прикладной логике: сценарий объекта не
  предполагает повторный выбор из 5 ранее выбранных вариантов либо в модуле менеджера
  переопределён `ОбработкаПолученияДанныхВыбора` — его условия механизм истории не учитывает (2.1).
- Свойства полей можно не изменять, если у поля режим выбора из списка с заполненным списком либо
  объект имеет `Быстрый выбор` (2.2).
