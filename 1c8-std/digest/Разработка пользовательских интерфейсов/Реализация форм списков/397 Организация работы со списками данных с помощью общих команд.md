# Организация работы со списками данных с помощью общих команд (#std397)

**Суть.** Одна параметризуемая форма списка и общие команды вместо похожих форм.

**Совет**
- Разработать параметризуемую форму списка: по параметрам она даёт состав колонок, отборы, порядок
  и заголовок (2).
- Назначить её основной формой списка объекта; без параметра она открывается как основная (2).
- Завести общие команды, открывающие форму с нужным параметром, и разместить в командном
  интерфейсе; заголовок формы — название команды (2).
- Настройки рабочего места (отборы) сохранять раздельно — `КлючНазначенияИспользования` (2).
- Когда одна форма не оправдана, допустимы отдельные общие формы и столько же общих команд (3).
- Комбинировать подходы возможно, предпочтительна одна параметризуемая форма (4).
- Образец такой формы — `Задача.ЗадачаИсполнителя.ФормаСписка` в «Библиотеке стандартных
  подсистем» (2).
