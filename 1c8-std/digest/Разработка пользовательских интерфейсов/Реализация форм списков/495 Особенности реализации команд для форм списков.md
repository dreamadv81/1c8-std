# Особенности реализации команд для форм списков (#std495)

**Суть.** В выделенных строках списка могут оказаться строки группировки.

**Совет**
- Команде в форме динамического списка учитывать, что пользователь мог сгруппировать список по
  одной из колонок (текст).
- Строки группировки, обработка которых логикой не предусмотрена, пропускать по `ТипЗнч` (текст).
- Когда в списке выделена только одна строка группировки, выдавать сообщение «Команда не может быть
  выполнена для указанного объекта.» (текст).

См. также: 558 (обновление списков).
