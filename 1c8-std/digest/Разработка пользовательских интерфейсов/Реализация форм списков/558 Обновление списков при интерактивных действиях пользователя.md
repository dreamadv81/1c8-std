# Обновление списков при интерактивных действиях пользователя (#std558)

**Суть.** Стандартные команды (`Записать`, `Провести`, `Пометить на удаление` и т. п.) и
добавление элементов платформа отрабатывает сама, остальное обновляет прикладной код.

**Обязательно**
- Вне стандартных команд обновление списка предусматривать явно в прикладном коде (1).
- Команды формы списка, изменяющие объекты, обновляют список после выполнения (2).
- Обновлять и список без основной таблицы: он показывает данные нескольких таблиц (3).
- Данные добавила или изменила команда формы списка — обновить список явно (3.1).
- Данные меняет другая форма — обновлять через оповещение: в форме объекта обработчик `ПослеЗаписи`
  вызывает `Оповестить("Запись_<ИмяОбъекта>", ПараметрыОповещения, ОбъектСсылка)`, где
  `Запись_<ИмяОбъекта>` — имя события, `<ИмяОбъекта>` — имя объекта, как оно задано в метаданных
  (`Запись_РасходнаяНакладная`), `ПараметрыОповещения` — как правило, параметр события
  `ПослеЗаписи`, `ОбъектСсылка` — ссылка на записываемый объект (3.2).
- Имена событий в `ОбработкаОповещения` проверять явно: иначе список обновляется неоправданно (3.2).
- При изменении нескольких объектов передавать в `ОбъектСсылка` метода `Оповестить` значение
  `Неопределено` (3.3).

**Совет**
- После изменения одного объекта вызывать `ОповеститьОбИзменении` (2).
- Несколько объектов — обновлять список однократно, в конце операции (2).
