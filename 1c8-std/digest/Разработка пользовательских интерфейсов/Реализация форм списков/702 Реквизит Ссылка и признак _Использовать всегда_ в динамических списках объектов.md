# Реквизит Ссылка и признак "Использовать всегда" в динамических списках объектов (#std702)

**Суть.** Поле `Ссылка` в списке нужно пользователю и механизмам платформы и «Библиотеки
стандартных подсистем».

**Обязательно**
- В БСП реквизит `Ссылка` с признаком «Использовать всегда» обязателен для команд печати
  (подсистема «Печать») (1).

**Не надо**
- Признак «Использовать всегда» у колонки реквизита списка (её данные получаются всегда, вне
  зависимости от видимости), кроме случаев, когда значение колонки обязательно для выполнения
  алгоритма (2.2).

**Совет**
- В динамические списки объектов ссылочных типов добавлять поле `Ссылка` с отключённой
  пользовательской видимостью: реквизиты пользователь выведет командой «Еще» — «Изменить
  форму» (1).
- При механизме характеристик платформы (подсистема «Свойства» БСП) всегда выводить `Ссылка`:
  характеристики выводятся в колонки только настройкой в пользовательском режиме (1).
- Обращаясь к данным строки (`ПриАктивацииСтроки`, `ПриПолученииДанныхНаСервере`), помнить: данные
  невидимых колонок не получаются, видимостью управляет и пользователь (2.1).
