# Настройка обмена данными для классификаторов между различными информационными базами (#std637)

**Суть.** Классификаторы — справочники и регистры сведений, одинаковые во всех базах; обмен
настраивают «Конвертацией данных».

**Обязательно**
- Классификаторы объектного типа сопоставлять по идентификаторам ссылок: в правиле конвертации
  объекта (ПКО) — «Искать объект приемника по внутреннему идентификатору объекта источника» и
  «Продолжить поиск по полям поиска, если по идентификатору объект приемник не найден», правила
  конвертации свойств полей поиска, при сложной идентификации — обработчик «Поля поиска» (2).
- Наборы записей поддерживать в каждой базе отдельно (3).

**Не надо**
- Включать наборы записей в обмен (3).
