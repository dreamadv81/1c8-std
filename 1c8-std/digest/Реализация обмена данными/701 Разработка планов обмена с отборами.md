# Разработка планов обмена с отборами (#std701)

**Суть.** Рекомендация (полезный совет) о логике регистрации, когда обмен идёт частью данных —
в разрезе организаций, складов, подразделений.

**Обязательно**
- Данные обмена самодостаточны: таблицы содержат всё нужное для логики регистрации — статья
  зовёт это требованием самодостаточности (2.1).

**Не надо**
- Обращаться в логике регистрации к полям связанных таблиц: она оперирует только данными
  основной таблицы, изменения которой регистрирует (2.1).
- Прерывать логику регистрации аварийно, когда нужных ей данных нет (2.3).

**Совет**
- Узлы-получатели определять в событиях `ПередЗаписью` и `ПередУдалением` объектов базы,
  предусмотрев там логику регистрации (1.1).
- В подсистеме «Обмен данными» БСП логику регистрации можно задать декларативно правилами
  регистрации объектов (ПРО) «Конвертации данных» (1.1).
- Проектируя логику регистрации, учитывать: данные сообщения загружаются в произвольном порядке
  и нужных ей данных может ещё не быть; при загрузке она идёт в транзакции записи объекта,
  `ОбменДанными.Загрузка` игнорируется, и любая её ошибка аварийно завершает загрузку;
  в распределённой информационной базе (РИБ) участвуют не все данные — движения мигрируют,
  регистраторы нет; обращение к связанным таблицам «через точку» даёт неявные соединения и
  тормозит обмен (1.2).
- В БСП при синхронизации с другими программами (не РИБ, по правилам конвертации) первые два
  пункта для ссылочных типов (`СправочникСсылка`, `ДокументСсылка`) не нужны: такие объекты
  регистрируются отложенно после загрузки всего сообщения (1.2).
- Когда самодостаточность поддержать нельзя, рассмотреть варианты — исключить вторичные данные
  либо регистрировать изменения связанных (2).
- Вторичные данные, вычисляемые независимо в каждой базе, исключать из плана обмена (2.2).
- Изменения всех взаимосвязанных таблиц регистрировать к выгрузке, для какой бы из них ни шла
  логика регистрации (2.3).

См. также: 464 (обработчик ПередЗаписью), 752 (обработчик ПередУдалением), 477 (самодостаточность регистров), 654 (разыменование ссылочных полей).
