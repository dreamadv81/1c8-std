# Интеграция прикладных решений через формат EnterpriseData (#std771)

**Суть.** Обмены между конфигурациями с БСП — на формате `EnterpriseData` со всеми актуальными
версиями.

**Обязательно**
- Переходы конфигураций — на правилах конвертации (ПК), обмены между конфигурациями с
  «Библиотекой стандартных подсистем» (БСП) — на формате `EnterpriseData` (1).
- Актуальные версии — «Пакет XDTO» `EnterpriseData_{X|XX}_{Y|YY}_{Z|ZZ}` в последней версии
  БСП (2).
- В новых версиях решений поддерживать все актуальные версии формата; исключение — пункт 4 (3).
- Состав свойств формата расширять согласованными изменениями формата (6).

**Не надо**
- Разрабатывать новые обмены на ПК, кроме решений для бюджетных организаций (1).
- Выпускать версию конфигурации без версии формата из её версии БСП (3).
- Поддерживать версию формата, не отвечающую требованиям к функциональности обмена (4).
- Передавать сведения между базами свойством `AdditionalInfo` в типовых обменах: разрешено ради
  поддержки законодательства без времени на новую версию формата и для обхода критических ошибок,
  блокирующих синхронизацию; добавленное придётся долго поддерживать ради совместимости (6).

**Совет**
- Информировать пользователей, какие версии формата поддержаны в решении (5).
