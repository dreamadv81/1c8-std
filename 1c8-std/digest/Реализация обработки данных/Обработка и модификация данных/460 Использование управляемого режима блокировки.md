# Использование управляемого режима блокировки (#std460)

**Суть.** В управляемом режиме чужая транзакция встаёт на чтении только при несовместимых
управляемых блокировках; автоматический режим изолирует данные сам, но даёт избыточные блокировки
СУБД: физического смысла объектов метаданных СУБД не знает.

**Обязательно**
- Свойство конфигурации `Режим управления блокировкой данных` — значение `Управляемый`, с учётом
  особенностей этого режима (текст).
- Явную управляемую блокировку ставить перед чтением данных: если считанное потом изменяется либо
  если неизменность считанного нужна до конца транзакции (текст).
- Стремиться блокировать только те записи, которые код обработает (текст).

**Не надо**
- Применять в запросах конструкцию `ДЛЯ ИЗМЕНЕНИЯ`: в этом режиме она смысла не имеет (текст).

См. также: 648 (ответственное чтение), 659 (избыточные блокировки).
