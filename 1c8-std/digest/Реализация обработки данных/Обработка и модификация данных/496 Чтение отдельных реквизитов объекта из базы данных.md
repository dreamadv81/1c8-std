# Чтение отдельных реквизитов объекта из базы данных (#std496)

**Суть.** `ПолучитьОбъект` и обращение к реквизиту через точку от ссылки загружают объект из базы
целиком, вместе с табличными частями.

**Обязательно**
- Значения отдельных реквизитов читать из базы запросом (текст).

**Не надо**
- Получать отдельные реквизиты через точку от ссылки или методом `ПолучитьОбъект` (текст).

**Совет**
- Ради простоты синтаксиса брать функции `ЗначенияРеквизитовОбъекта` и `ЗначениеРеквизитаОбъекта`
  из Библиотеки стандартных подсистем (текст).
