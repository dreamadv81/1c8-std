# Запись событий в историю работы пользователя (#std497)

**Суть.** Интерактивное добавление или изменение объектов платформа пишет в историю сама.

**Совет**
- Записывать в историю и другие события, записывающие объекты по действию пользователя, например
  команду «Поместить файл» (текст).
- Добавлять их объектом `ИсторияРаботыПользователя` типа `МенеджерИсторииРаботыПользователя`
  (текст).

**Пример**
```bsl
ИсторияРаботыПользователя.Добавить(ПолучитьНавигационнуюСсылку(Объект.Ссылка));
```
