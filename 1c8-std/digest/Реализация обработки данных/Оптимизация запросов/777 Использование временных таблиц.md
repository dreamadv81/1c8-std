# Использование временных таблиц (#std777)

**Суть.** Временные таблицы — про производительность.

**Обязательно**
- Большой объём данных — порциями (2.1).
- Максимально ограничивать выбираемые данные (2.2).
- Индексировать всегда, когда это даст прирост (3).
- Большая таблица в соединении — индекс по полям `ПО` (3.1.1).
- Подзапрос `В (…)` — индекс по полям таблицы, отвечающим левой части (3.1.2).
- Несколько условий — индекс для часто проверяемого (3.3).

**Не надо**
- Таблицы в сотни тысяч записей (2.1).
- Данные и поля, не нужные последующим запросам (2.2, 2.3).
- Создавать и удалять таблицы в цикле вместо одной (2.4).
- Копировать таблицу вместо передачи имени (2.5).
- Индексировать таблицы менее 1000 записей (3.2).

**Совет**
- Использовать ради производительности и стабильности (1).
- Для других целей — помня о падении скорости (1).

условии соединения).
