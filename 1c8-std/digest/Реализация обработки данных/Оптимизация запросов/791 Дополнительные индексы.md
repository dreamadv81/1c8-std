# Дополнительные индексы (#std791)

**Суть.** Дополнительный индекс — индекс по нескольким полям с включаемыми полями.

**Обязательно**
- Применять для крупных предприятий с КОРП лицензиями (1).
- Производительность без дополнительных индексов должна быть приемлемой ориентировочно до
  `100 000 – 1 000 000` записей, выше — с ними (2).
- Тестировать и оптимизировать производительность в обоих режимах (2).
- Использовать обычные индексы, если производительность достижима без дополнительных (3).

**Не надо**
- Дополнительные индексы, если лицензии только ПРОФ (1).

**Совет**
- Держать одну ветку кода (4).
- Альтернативное решение — исключение, когда минимальной производительности нет: операции до
  1 секунды, отчёты не медленнее вдвое (4.1).
- Поле не из условий запроса делать включаемым, а не ключевым (5).
