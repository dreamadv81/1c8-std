# Использование ключевых слов "ОБЪЕДИНИТЬ" и "ОБЪЕДИНИТЬ ВСЕ" в запросах (#std434)

**Суть.** `ОБЪЕДИНИТЬ` тратит время на замену полностью одинаковых строк одной — даже когда таких
строк заведомо быть не может.

**Обязательно**
- При объединении результатов нескольких запросов в общем случае использовать `ОБЪЕДИНИТЬ ВСЕ`, а
  не `ОБЪЕДИНИТЬ` (текст).
- Исключение — когда замена одинаковых строк одной необходима для выполнения запроса (текст).
