# Многократное выполнение однотипных запросов (#std436)

**Суть.** Серия однотипных запросов в цикле дороже одного общего запроса.

**Совет**
- Получать все однотипные данные одним запросом вместо серии: объединяют условие `В`,
  `ОБЪЕДИНИТЬ ВСЕ` и пакет запросов (1).
- С Библиотекой стандартных подсистем звать интерфейс для списков объектов:
  `ОбщегоНазначения.ЗначениеРеквизитаОбъектов` вместо `ЗначениеРеквизитаОбъекта` в цикле (1).
- Запросы к разным таблицам тоже объединять `ОБЪЕДИНИТЬ ВСЕ` или пакетом, хотя выигрыш бывает
  незначительным (3).
- Серия запросов допускается при заметном усложнении разработки общего запроса, деградации
  производительности (виртуальные таблицы на дату) и порционной обработке большого объёма —
  обновление, групповое проведение, изменение и удаление данных, загрузка данных (2).
