# Проверка на пустой результат выполнения запроса (#std438)

**Суть.** Пустоту результата запроса проверяют методом `Пустой`: получение выборки ради той же
проверки тратит время.

**Обязательно**
- Проверку того, что результат выполнения запроса не содержит строк, выполнять методом `Пустой`, а
  не получением выборки (1).

**Совет**
- Когда результат запроса всё равно требуется выбрать или выгрузить, предварительный вызов метода
  `Пустой` не обязателен (2).
