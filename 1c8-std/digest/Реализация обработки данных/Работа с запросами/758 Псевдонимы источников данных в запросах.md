# Псевдонимы источников данных в запросах (#std758)

**Суть.** Требования к псевдониму источника данных схожи с требованиями к именам переменных в коде.

**Обязательно**
- Псевдоним источника данных должен быть осмысленным, чтобы его назначение в данном контексте было
  понятно (1).
- Образовывать псевдонимы от терминов предметной области — так, чтобы было понятно, как источник
  используется в запросе (1).
- Образовывать псевдонимы удалением пробелов между словами, каждое слово с прописной буквы
  (`ТоварыНаСкладах`); предлоги и местоимения из одной буквы тоже прописные (1).

**Не надо**
- Начинать псевдоним с подчёркивания — запрещается (1).
- Псевдоним из одного символа (1).
- Имена классов объектов метаданных («Справочник», «Документ»): такой псевдоним не описывает
  назначение источника в конкретном запросе (1).

**Совет**
- Универсальные псевдонимы допустимы в универсальных механизмах и запросах, где вместо источника
  при исполнении подставляется имя конкретной таблицы (2).

См. также: 454 (имена переменных).
