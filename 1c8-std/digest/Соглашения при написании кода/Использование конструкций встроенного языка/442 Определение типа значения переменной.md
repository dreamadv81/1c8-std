# Определение типа значения переменной (#std442)

**Суть.** Тип значения узнают сравнением с типом.

**Обязательно**
- Тип значения переменной определять сравнением с типом: `ТипЗнч(Ссылка) =
  Тип("ДокументСсылка.ПоступлениеТоваровУслуг")`, а не каким-либо другим методом, например
  `Ссылка.Метаданные().Имя = "ПоступлениеТоваровУслуг"` (текст).
