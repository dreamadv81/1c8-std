# Обработчики событий модуля формы, подключаемые из кода (#std492)

**Суть.** Подключение обработчика вне текста модуля формы даёт при проверке конфигурации ошибку
«Не обнаружено ссылок на процедуру»; префикс позволяет опознать такие обработчики и отсеять их как
исключения.

**Совет**
- Обработчикам событий модуля формы, которые устанавливаются из кода методом `УстановитьДействие`,
  задавать префикс `Подключаемый_` (англ. `Attachable_`) (текст).
