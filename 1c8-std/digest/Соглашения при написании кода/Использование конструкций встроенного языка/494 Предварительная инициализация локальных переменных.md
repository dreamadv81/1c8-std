# Предварительная инициализация локальных переменных (#std494)

**Суть.** Неинициализированная переменная равна `Неопределено`, а код дальше рассчитывает на
определённый тип — отсюда ошибки времени выполнения.

**Совет**
- Когда фрагмент кода вычисляет значение одной или нескольких локальных переменных, явно выполнять
  предварительную инициализацию таких переменных значением по умолчанию (текст).
- Рекомендация имеет смысл для больших блоков `Если`/`ИначеЕсли`/`Иначе`, где инициализацию сложно
  контролировать по тексту (текст).
