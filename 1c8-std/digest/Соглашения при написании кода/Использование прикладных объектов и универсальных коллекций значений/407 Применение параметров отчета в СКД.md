# Применение параметров отчета в СКД (#std407)

**Суть.** Параметр отчёта — крайнее средство: отбором пользователь управляет сам.

**Обязательно**
- Обязательные параметры заменять элементами расширения языка запросов СКД `{ГДЕ...}`: параметры
  необязательны, при отключении отключается свой фрагмент условия (текст).

**Не надо**
- Параметр отчёта там, где хватает управления элементами отбора: условие
  `ГДЕ Организация = &Организация` заменяется отбором (текст).
- Обязательные параметры: отключив такой, пользователь получает ошибку «Не задан параметр
  отчета» (текст).
