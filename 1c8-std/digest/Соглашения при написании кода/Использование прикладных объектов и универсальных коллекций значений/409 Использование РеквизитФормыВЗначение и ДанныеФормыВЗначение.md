# Использование РеквизитФормыВЗначение и ДанныеФормыВЗначение (#std409)

**Суть.** По эффективности и результату методы работают одинаково; `РеквизитФормыВЗначение`
существует ради удобства: синтаксис проще, тип значения передавать не нужно, ошибиться труднее.

**Совет**
- В модулях форм в большинстве случаев использовать метод формы `РеквизитФормыВЗначение` вместо
  метода `ДанныеФормыВЗначение` (текст).
