# Установка параметров выбора и связей параметров выбора для объектов метаданных (#std411)

**Суть.** Ограничения выбора живут в свойствах объектов метаданных и работают во всех формах; в
форме их лишь уточняют, а безусловная очистка зависимого реквизита стирает ещё допустимые значения.

**Обязательно**
- Ограничения выбора, как правило, одинаковы для всех форм, в которых редактируется объект (1).
- Вместо безусловной очистки писать программный код, выполняющий условную очистку зависимого
  значения при несоответствии новым значениям ведущих реквизитов (4).
- В самой связи параметра выбора вместо `Очищать` ставится `Режим изменения связанного
  значения` = `Не изменять` (4, рис.).

**Не надо**
- `Режим изменения связанного значения` = `Очищать` в связях параметров выбора: при повторном
  выборе ведущего значения (без реального изменения) зависимый реквизит будет очищен, а если
  значение зависимого реквизита может соответствовать нескольким значениям ведущего — очищено
  и тогда, когда оно остаётся допустимым (4).

**Совет**
- Параметры выбора и связи параметров выбора (между зависимым и ведущими реквизитами) задавать в
  свойствах объектов метаданных — в реквизитах справочников, документов и т. п. (1).
- Ограничения выбора, зависящие от конкретного сценария работы, уточнять по месту, в конкретной
  форме (2).
- Связь, заданная в свойствах реквизита, и связь, установленная программно у поля формы, в режиме
  `1С:Предприятия` работают обе (2).
- Задавать параметры выбора и для объектов, которые не редактируются интерактивно: они
  учитываются при выборе значений в отборах отчётов и динамических списков (3).
- Безусловная очистка (`Режим изменения связанного значения` = `Очищать`) допустима, когда
  повторный выбор значения ведущего реквизита без фактического изменения невозможен и каждому
  значению зависимого реквизита соответствует не более одного значения ведущего (4.1).
- Для заполнения реквизитов нового объекта, создаваемого из поля или формы выбора с
  установленными отборами, добавлять нужные параметры выбора в структуру `Отбор`, ставя перед
  именем параметра префикс «`Отбор.`»: её свойства и значения передаются в параметр
  `ДанныеЗаполнения` события `ОбработкаЗаполнения` (5, рис.).
