# Использование объекта РегистрСведенийМенеджерЗаписи (#std447)

**Суть.** Менеджер записи пишет двумя наборами записей и вызывает обработчики событий набора, а по
производительности бывает не лучше набора записей, иногда и хуже — из-за лишних действий.

**Обязательно**
- Чтение записи (набора записей) из регистра сведений без последующей модификации выполнять
  запросом (1).
- `РегистрСведенийМенеджерЗаписи` применять только тогда, когда операции с регистром сведений
  требуют отбора одновременно по всем измерениям (2).
- В остальных случаях использовать `РегистрСведенийНаборЗаписей` (3).
