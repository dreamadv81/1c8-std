# Копирование строк между таблицами значений (табличными частями и т.п.) произвольной структуры (#std448)

**Суть.** Сопоставление колонок делает платформа: это значительно эффективнее многократного
перебора колонок в коде.

**Обязательно**
- При копировании строк между различными таблицами значений (табличными частями и т. п.) со
  схожим составом колонок использовать метод глобального контекста `ЗаполнитьЗначенияСвойств`
  (текст).
