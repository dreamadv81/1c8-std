# Получение представлений для ссылочных значений в табличном документе (#std449)

**Суть.** Ссылка в параметре ячейки — обращение к базе за представлением в момент вывода.

**Не надо**
- Ссылочные значения в параметрах ячеек с типом заполнения `Параметр` — запрещено: при выводе база
  многократно опрашивается за представлениями (текст).

**Совет**
- Параметрами указывать сами представления (текст).
- Исключение — за представлениями придётся идти в базу так же многократно (текст).
- Представление из самого запроса (поле `Представление`, функция
  `Представление(<Имя поля>)`) даёт неявное соединение с таблицей объекта, а у поля составного
  типа — по соединению на каждый тип: запрос выполняется дольше, а при многих типах в
  клиент-серверной версии не выполнится: `Microsoft SQL Server 2005` не берёт больше 256
  таблиц; такие случаи тоже бывают исключением (текст).
- Однозначно рекомендовать способ нельзя — выбирает разработчик, по экспериментальным
  данным (текст).
