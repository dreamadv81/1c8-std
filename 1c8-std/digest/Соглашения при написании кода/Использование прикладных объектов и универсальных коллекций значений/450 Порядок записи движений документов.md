# Порядок записи движений документов (#std450)

**Суть.** Движения пишет система при завершении проведения; явная запись грозит взаимными
блокировками при параллельной работе.

**Обязательно**
- Наборы записей регистров записывает система неявно, при завершении процедуры проведения (1).

**Не надо**
- Явная запись наборов записей регистров (метод `Записать`) в процедурах обработки проведения
  документов (1).

**Совет**
- Исключение — данные регистров нужны последующим алгоритмам до выхода из процедуры
  проведения (2).

См. также: 603 (проведение документов), 477 (самодостаточность регистров), 633 (активность движений).
