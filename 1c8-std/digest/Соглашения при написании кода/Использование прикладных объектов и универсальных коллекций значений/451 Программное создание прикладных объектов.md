# Программное создание прикладных объектов (#std451)

**Суть.** Объект создают менеджером и заполняют явно — иначе не отработают «Значение заполнения»,
`ОбработкаЗаполнения` и подписки.

**Обязательно**
- Прикладные объекты создавать методами соответствующих менеджеров: `СоздатьЭлемент`,
  `СоздатьДокумент`, `СоздатьНаборЗаписей`, … (1).
- При создании объекта явно вызывать метод `Заполнить`; нет данных — передавать
  `Неопределено` (2).

**Не надо**
- Конструктор `Новый` для объектов, у которых есть менеджеры объектов (1).

**Совет**
- Исключение — объект целиком загружается при обмене данными или восстановлении базы из
  копии (2).
