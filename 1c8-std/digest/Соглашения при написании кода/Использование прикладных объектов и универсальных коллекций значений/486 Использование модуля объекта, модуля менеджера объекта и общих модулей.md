# Использование модуля объекта, модуля менеджера объекта и общих модулей (#std486)

**Суть.** Код кладут по принадлежности — экземпляру, объекту метаданных, нескольким сразу.

**Не надо**
- Функции модуля менеджера объекта, требующие экземпляра объекта данных
  (`СправочникОбъект`, `ДокументОбъект`) (2).

**Совет**
- В модуле объекта — работа с данными объекта (`ЭтотОбъект`, переменные модуля объекта), в том
  числе до записи в базу (1).
- Вызов экспортных процедур модуля объекта извне может потребовать `ПолучитьОбъект` —
  ресурсоёмкую загрузку объекта целиком (1).
- В модуле менеджера — «статическая» функциональность объекта метаданных, не зависящая от
  экземпляра: для совокупности объектов и по ссылке на записанный (2).
- Что нельзя однозначно отнести к объекту метаданных — в общий модуль (3).

См. также: 496 (чтение отдельных реквизитов).
