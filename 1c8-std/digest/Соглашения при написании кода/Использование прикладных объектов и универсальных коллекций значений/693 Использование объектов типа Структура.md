# Использование объектов типа Структура (#std693)

**Суть.** Требования к `Структура` — про читаемость кода и правку его разными авторами:
конструктор не перегружают, состав свойств объявляют сразу.

**Обязательно**
- Структуру сразу создавать со значением свойств по умолчанию: это читаемость и работа
  средств автоматической проверки и обработки кода (4.1).
- Пользовательские параметры формы объявлять явно на закладке `Параметры` редактора формы (4.2).

**Не надо**
- Передавать в конструктор `Структура` более 3-х значений свойств: вместо этого метод `Вставить`
  или явное присваивание свойствам (1).
- Конструкторы других объектов, принимающие параметры, в конструкторе структуры; в частности —
  создание в нём других структур с объявлением значений свойств (2).
- Вызовы функций с большим (более 3) количеством параметров в конструкторе структуры (3).
- Добавлять свойства в структуру в разных частях кода и затем проверять их наличие (4.1).

**Совет**
- Исключение — структуры, формат которых не фиксирован: полученные из внешних источников
  (результат HTTP-запроса, данные со сканера штрихкодов, терминала сбора данных), системные
  параметры формы и параметры выбора в параметрах формы (4.2).

См. также: 640 (параметры процедур), 641 (структуры параметрами), 741 (параметры формы).
