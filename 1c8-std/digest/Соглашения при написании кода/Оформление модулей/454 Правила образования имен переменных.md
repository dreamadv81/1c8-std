# Правила образования имен переменных (#std454)

**Суть.** Имя переменной называет её назначение словами предметной области.

**Обязательно**
- Имена переменных — от терминов предметной области: назначение понятно из имени (1).
- Имя — слова без пробелов, каждое с прописной буквы; предлоги и местоимения из одной буквы
  тоже (2).
- Переменную-флаг называют так, как пишется его истинное значение (5).

**Не надо**
- Начинать имя с подчёркивания запрещено (3).
- Имя из одного символа; односимвольные — только для счётчиков циклов (4).

См. также: 639 (переменные модуля).
