# Обработчик события ОбработкаЗаполнения (#std396)

**Суть.** Обработчик ограничивает ввод на основании и заполняет реквизиты нового объекта.

**Обязательно**
- Проверки, ограничивающие ввод по команде «Создать на основании», выполнять в
  `ОбработкаЗаполнения` модуля объекта (набора записей) (1).
- Для оповещения пользователя о причинах отказа использовать исключения (2).

**Не надо**
- Иные решения для подобных проверок; в частности, дополнительные команды ввода на основании с
  проверками в их обработчиках (2).

**Совет**
- Придерживаться структуры обработчика: сначала специальное заполнение в зависимости от типа параметра
  `ДанныеЗаполнения`, затем общее заполнение значениями по умолчанию; отдельные шаги могут быть
  пропущены (3).
- Перед общим заполнением проверять реквизит на заполненность, а значения по умолчанию по возможности
  задавать свойством «Значение заполнения»: оно присваивается при выходе из обработчика, если
  `СтандартнаяОбработка` — `Истина` и реквизит не заполнен (3.2).

**Пример**
```bsl
Если ПолучитьЗначениеРеквизита(ДанныеЗаполнения, "ЭтоГруппа") = Истина Тогда
   ВызватьИсключение "Ввод приказа о приеме на основании группы сотрудников невозможен!";
КонецЕсли;
```
См. также: 499 (перехват исключений), 536 (обращение к элементам формы).
