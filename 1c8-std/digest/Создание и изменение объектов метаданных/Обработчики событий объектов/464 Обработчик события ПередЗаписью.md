# Обработчик события ПередЗаписью (#std464)

**Суть.** Обработчик модуля объекта: дозаполнение реквизитов, предпроверки, «старые» значения из базы.

**Обязательно**
- В `ПередЗаписью` выполнять, как правило, заполнение реквизитов объекта (набора записей, значения константы),
  проверки правильности заполнения и связанности состояния объекта с внешними данными (1).
- Здесь же обращаться к «старым», сохранённым в базе значениям реквизитов — при редактировании ранее
  записанных объектов (1).
- Все действия обработчика — после проверки на `ОбменДанными.Загрузка` (2).

**Пример**
```bsl
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
  Если ОбменДанными.Загрузка Тогда
     Возврат;
  КонецЕсли;
  // Предпроверки и дозаполнение реквизитов объекта
КонецПроцедуры
```
См. также: 773 (признак ОбменДанными.Загрузка), 463 (проверки в транзакции записи и вне её).
