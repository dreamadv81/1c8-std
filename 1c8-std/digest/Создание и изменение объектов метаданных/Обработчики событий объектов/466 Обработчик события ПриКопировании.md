# Обработчик события ПриКопировании (#std466)

**Суть.** Обработчик модуля объекта отрабатывает создание нового объекта копированием.

**Обязательно**
- В `ПриКопировании` выполнять действия, связанные с созданием нового объекта копированием (текст).
- Здесь же очищать содержимое реквизитов, значения которых не должны сохраняться при копировании (текст).
