# Обработчик события ПередУдалением (#std752)

**Суть.** Обработчик модуля объекта для действий перед удалением.

**Обязательно**
- В `ПередУдалением` выполнять, как правило, действия, необходимые перед удалением объекта (1).
- Все действия обработчика — после проверки на `ОбменДанными.Загрузка`: при удалении через обмен данными
  они выполняться не должны, иначе возможны ошибки (2).

См. также: 773 (признак ОбменДанными.Загрузка).
