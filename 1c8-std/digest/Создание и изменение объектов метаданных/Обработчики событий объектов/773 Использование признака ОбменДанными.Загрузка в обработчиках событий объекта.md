# Использование признака ОбменДанными.Загрузка в обработчиках событий объекта (#std773)

**Суть.** Проверка отключает бизнес-логику при загрузке: в узле-источнике она уже выполнена,
данные ложатся «как есть».

**Обязательно**
- Все действия обработчиков `ПередЗаписью`, `ПриЗаписи`, `ПередУдалением` выполнять после проверки на
  `ОбменДанными.Загрузка` (1).
- Механизмы, не рассчитанные на особенности конфигураций, обязаны при установленном флаге загружать
  данные так, будто текста обработчика нет: без искажений и проверок (1).
- Те же требования — в обработчиках подписок (3).
- Исключение — механизм обмена данными, регистрирующий загружаемые данные к выгрузке на других узлах;
  чтобы отключить эту подсистему БСП, устанавливать `ОтключитьМеханизмРегистрацииОбъектов` (2).
- Причину другого исключения описывать в комментарии (2).
- Вызывающая сторона, выставляя `ОбменДанными.Загрузка` в `Истина`, отвечает за целостность данных
  объекта: при конвертации или формате `EnterpriseData` сама дозаполняет объект (4).

**Совет**
- Действия по дозаполнению размещать в экспортных процедурах самого объекта (4).

**Пример**
```bsl
Процедура ПередЗаписью(Отказ)
Если ОбменДанными.Загрузка Тогда
     Возврат;
КонецЕсли;
// код обработчика
КонецПроцедуры
```
См. также: 464, 465, 752 (обработчики записи и удаления), 771 (формат EnterpriseData).
