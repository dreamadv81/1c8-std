# Использование параметров сеанса (#std413)

**Суть.** Параметры сеанса живут на сервере и устанавливаются «по требованию» в модуле сеанса.

**Обязательно**
- Параметры сеанса инициализировать в модуле сеанса и устанавливать «по требованию» в обработчике
  `УстановкаПараметровСеанса`: параметр инициализируется при первом обращении к нему как к
  неустановленному (1.1, 2.1).
- Для установки и получения значения параметра сеанса из встроенного языка у пользователя должно
  быть соответствующее право; в текстах ограничений доступа оно не требуется (1.1).

**Не надо**
- Инициализировать параметры сеанса при запуске программы: запрашиваются из кода не все, а значения
  параметров при работе могут намеренно обнуляться (2.1).
- Хранить в параметрах сеанса значения, нужные только клиентской логике: каждое чтение с клиента —
  лишний серверный вызов, для этого есть глобальные переменные модуля управляемого (обычного)
  приложения (1.2).
- Кешировать параметрами сеанса вычисленные значения, многократно нужные серверной бизнес-логике:
  для этого есть функции серверного общего модуля с повторным использованием возвращаемых значений;
  исключение — когда время вычисления соизмеримо с периодом сброса платформенного кеша (1.3).

**Совет**
- Значения параметров сеанса использовать в запросах и условиях ограничения доступа к данным
  текущего сеанса (1.1).

См. также: 491 (влияние параметров сеанса на производительность ограничения доступа).
