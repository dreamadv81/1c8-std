# Использование подсистем (#std543)

**Суть.** Подсистемы решают две задачи: командный интерфейс и группировку объектов для разработки;
вся статья — методическая рекомендация.

**Совет**
- У подсистем-разделов командного интерфейса флажок `Включать в командный интерфейс` установлен (1.1).
- Для логического объединения объектов по функциональному признаку заводить отдельную иерархию
  «функциональных» подсистем со снятым флажком `Включать в командный интерфейс` (1.2).
- Объекты без визуального представления в командном интерфейсе — общие модули, регламентные
  задания, константы, подписки на события — включать только в «функциональные» подсистемы (1.3).
