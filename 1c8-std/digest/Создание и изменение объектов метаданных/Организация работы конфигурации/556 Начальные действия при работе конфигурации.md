# Начальные действия при работе конфигурации (#std556)

**Суть.** Конфигурация сама отрабатывает первый запуск и первый запуск нового релиза.

**Обязательно**
- Предусмотреть механизм, определяющий первый запуск конфигурации — с заполнением базы
  минимально необходимыми данными — и первый запуск нового релиза с обновлением данных; при
  `Библиотеке стандартных подсистем` — подсистемой «Обновление версии ИБ» (1).
- Случаи, когда обработка не проведена в требуемом объёме, контролировать и предупреждать
  пользователя; подробный протокол — в журнал регистрации (4).
- В распределённой базе обновлять данные подчинённого узла после загрузки обновлённых данных из
  главного и без повторной обработки тех же данных и создания новых: повторная обработка обязана
  отрабатывать корректно (5).

**Совет**
- Первоначальное заполнение делить на обязательное, без которого конфигурация не работает, и
  необязательное (2).
- По итогам первого запуска конфигурации или нового релиза выводить администратору описание
  конфигурации или её изменений (3).
