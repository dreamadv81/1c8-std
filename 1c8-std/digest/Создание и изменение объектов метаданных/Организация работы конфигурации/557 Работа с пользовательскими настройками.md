# Работа с пользовательскими настройками (#std557)

**Суть.** Персональные настройки живут в `ХранилищеОбщихНастроек` под уникальными ключами.

**Обязательно**
- Персональные настройки пользователя хранить в `ХранилищеОбщихНастроек`; для работы с ними нужно
  право `СохранениеДанныхПользователя` (1.1, 1.2).
- К каждой настройке в хранилище обращаться по уникальному строковому ключу (1.3).
- Предусмотреть общее место редактирования всех настроек — обычно общую форму
  персональных настроек (2.1).
- Форму персональных настроек, другие рабочие места и элементы форм для работы с настройками
  открывать только с правом `СохранениеДанныхПользователя` (2.3).
- Помнить, что настройки специфичны для узла базы и между узлами не мигрируют (3.1).

**Не надо**
- Хранить настройки пользователя иначе: в других объектах метаданных (регистры, реквизиты и
  табличные части справочников), во внешних файлах (1.1).

**Совет**
- Несколько настроек объединяют в структуру, массив или соответствие, если обращения к ним идут
  одновременно, как к одной (1.3).
- Отдельные настройки можно разместить полями прямо в рабочих местах, которым они принадлежат (2.2).
- Переносить настройки при переименовании пользователя и очищать при удалении: хранятся они по
  строковому имени, и тёзка получит чужие (3.2).

См. также: 488 (стандартные роли).
