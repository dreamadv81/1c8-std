# Использование общих реквизитов (#std677)

**Суть.** Общий реквизит решает одну из двух задач: разделение данных (`Разделение данных` —
`Разделять`) либо расширение состава реквизитов нескольких объектов (`Не использовать`).

**Обязательно**
- Общий реквизит без разделения данных заводить под функциональность вне бизнес-логики прикладных
  объектов, но требующую хранения данных в них самих; права доступа к нему настраиваются
  отдельно (2).
- Порядок общих реквизитов-разделителей в дереве метаданных подбирать по требуемому порядку
  установки связанных с ними параметров сеанса (3).

**Не надо**
- Переносить в общие реквизиты «обычные» реквизиты документов (`Ответственный`, `Комментарий`,
  `Организация`): для удобства добавления одинаковых реквизитов они не предназначены (2).

См. также: 413 (параметры сеанса).
