# Использование ботов системы взаимодействия (#std798)

**Суть.** Боты работают регламентным заданием с `СистемаВзаимодействия.ВыполнитьОбработкуБотов()`.

**Обязательно**
- Предусмотреть регламентное задание, вызывающее
  `СистемаВзаимодействия.ВыполнитьОбработкуБотов()` (1).
- В решениях для модели сервиса (Технология 1cFresh) предусмотреть настройки включения и
  отключения бота: при включении создавать бота программно, при выключении удалять (1.1).
- В решениях для модели сервиса задание одно, сколько бы объектов `БотСистемыВзаимодействия` ни
  было (1.2).
- При создании бота указывать пользователя системы взаимодействия, не связанного с пользователем
  базы: иначе тот не сможет в ней работать (2).
- Экземпляры ботов одного объекта метаданных связывать с разными пользователями `Системы
  взаимодействия`: иначе работает только последний (3).
- Код обработки сообщений ботов писать без необработанных исключений: сообщение с исключением
  остаётся в очереди, следующие не обрабатываются (4).

**Не надо**
- Предопределённые боты в конфигурации для модели сервиса (1.1).
- Включать это задание в модели сервиса в состав разделителей — оно неразделённое, иначе ресурсы
  серверов расходуются впустую (1.2).

См. также: 499 (перехват исключений в коде).
