# Уточнение сущности объекта метаданных (#std541)

**Суть.** Разные по смыслу сущности описывают разными объектами метаданных, а вид и состояние
объекта задают явным реквизитом, а не догадкой по косвенным признакам.

**Обязательно**
- Разные по смыслу сущности описывать разными типами объектов метаданных (1).

**Не надо**
- Трактовать вид объекта по косвенным признакам, в частности по заполненности того или иного
  реквизита (2).
- Пара булевых реквизитов на два состояния, когда состояние уже выводится из других реквизитов:
  `ПринятНаРаботу` и `Уволен` при наличии `ДатаПриема` и `ДатаУвольнения` не оправданы (3).

**Совет**
- Заводить отдельный реквизит, однозначно определяющий вид или состояние объекта, — типа
  `Булево` либо перечисление с видами объекта (2).
- Сущности с несколькими состояниями давать один реквизит-перечисление со статусами
  («работает», «уволен»), состав которых потом расширяется (3).
