# Настройка расписания регламентных заданий (#std402)

**Суть.** Интервал запуска выбирают по прикладному назначению: частое выполнение нагружает сервер.

**Обязательно**
- Периодичность заданий чаще раза в день соразмерять со временем выполнения: при типичных 20 секундах
  минутная периодичность избыточна (текст).
- Ресурсоёмкие операции по возможности переносить на время минимальной загрузки сервера: нерабочее время,
  выходные (текст).

**Не надо**
- Выполнять задание чаще, чем нужно с прикладной точки зрения (текст).
- Задавать периодичность меньше одной минуты — ни в каких случаях (текст).

**Совет**
- Для большинства заданий нормален интервал в 1 день; исключение — прикладная критичность частого
  выполнения (текст).
- Несколько ресурсоёмких заданий разносить по времени, исходя из ожидаемого времени выполнения (текст).

См. также: 540 (предопределённые задания), 539 (запуск заданий).
