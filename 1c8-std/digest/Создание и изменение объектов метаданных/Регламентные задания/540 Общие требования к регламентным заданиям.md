# Общие требования к регламентным заданиям (#std540)

**Суть.** Задание выполняет действия по расписанию; как его заводить, задают отключаемая
функциональность и зависимость от данных базы.

**Обязательно**
- Использовать регламентные задания для периодических или однократных действий по расписанию (1).
- Использовать предопределённые задания, когда их не требуется добавлять или удалять по действиям
  пользователя или логике конфигурации (2).
- Признаком `Использование` предопределённого задания управлять программно по включённым функциональным
  опциям; у зависящего от опции задания флажок снят (3.1).
- В конфигурациях на «Библиотеке стандартных подсистем» зависимость от опции описывать в
  `ПриОпределенииНастроекРегламентныхЗаданий` модуля `РегламентныеЗаданияПереопределяемый`, а в
  определяемый тип `МестоХраненияФункциональныхОпций` добавлять константы опций (3.1).
- Задание, включённое мимо функциональной опции, обезопасить: в начале процедуры обработки проверять
  опцию и вызывать исключение; при настроенных зависимостях в БСП хватает вызова из пункта 6 (3.2).
- Отключать флажок `Предопределенное`, когда выполнение задания зависит от данных информационной
  базы (4.1).
- Такие задания создавать методом `РегламентныеЗадания.СоздатьРегламентноеЗадание`, параметризовать
  объектами базы, а в `Наименование` писать представление объекта-основания (4.1).
- При БСП запрещать интерактивное создание и запуск параметризованных заданий из формы «Регламентные и
  фоновые задания», указав его со свойством `Параметризуется` в той же процедуре (4.2).
- При БСП в начале процедур-обработчиков заданий из пунктов 3.1, 4.2 и 5 помещать вызов
  `ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания` с обязательным первым параметром —
  метаданными задания (6).

**Не надо**
- Выполнять задания при отключённой функциональности: запуски сеансов занимают ресурсы сервера (3.1).

**Совет**
- В копиях базы (тестирование, техподдержка) автоматически блокировать задания, обращающиеся к
  внешним ресурсам. При БСП перечислять их со свойством
  `РаботаетСВнешнимиРесурсами` в той же процедуре: при перемещении базы администратору будет задан
  вопрос об отключении (5).

**Пример**
```bsl
Настройка = Настройки.Добавить();
Настройка.РегламентноеЗадание = Метаданные.РегламентныеЗадания.ОбновлениеСтатусовДоставкиSMS;
Настройка.ФункциональнаяОпция = Метаданные.ФункциональныеОпции.ИспользоватьПочтовыйКлиент;
```
