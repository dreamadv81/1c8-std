# Заполнение свойств конфигурации информацией о выпуске (#std482)

**Суть.** Свойства описывают выпуск.

**Обязательно**
- `Синоним` — название, через запятую «редакция» и номер (1).
- `Имя` — из синонима по правилам образования имён, без «редакция» и номеров (2).
- `Краткая информация`, `Подробная информация` — синоним (3, 4).
- `Заставка` — картинка поддерживаемого типа (6).
- `Авторские права` — «Copyright (C) <разработчик>, хххх-хххх. Все права защищены.», англоязычная — «All
  rights reserved.» (7).
- `Версия` — полный номер версии (11).
- У типовых «1С»: `Логотип` пустой, `Поставщик` — Фирма «1С», адреса поставщика
  https://www.1c.ru, обновлений https://downloads.v8.1c.ru/tmplts/, конфигурации
  https://v8.1c.ru/<короткое имя латиницей>/ (5, 8, 9, 10, 12).

См. также: 483 (нумерация редакций и версий).
