# Нумерация редакций и версий (#std483)

**Суть.** Номер версии — редакция, подредакция, версия, сборка.

**Обязательно**
- Номер очередной редакции начинать со следующего целого относительно предыдущей; у новых
  конфигураций — с 1.0 (1).
- Все версии подредакции — альфа, ознакомительные, бета, финальные — нумеровать подряд с 1 (2).
- Полный номер версии указывать в свойстве `Версия` конфигурации строкой `{Р|РР}.{П|ПП}.{З|ЗЗ}.{С|СС}` —
  редакция, подредакция, версия, сборка; каждый номер занимает минимум одну цифру, может и больше (3).

**Совет**
- Редакцию обозначать номером редакции через точку с подредакцией, например редакция 1.6 (1).

См. также: 484 (общие сведения о выпуске конфигураций).
