# Общие сведения о выпуске конфигураций (#std484)

**Суть.** Версия — исправление ошибок, редакция — изменение структуры учёта.

**Обязательно**
- Новая версия обязана обеспечивать переход с предыдущей с сохранением данных (2).
- Не удалось сохранить данные при переходе на редакцию — описать процедуру перехода (3).

**Совет**
- Обеспечивать переход на новую редакцию с сохранением данных (3).

См. также: 483 (нумерация редакций и версий).
