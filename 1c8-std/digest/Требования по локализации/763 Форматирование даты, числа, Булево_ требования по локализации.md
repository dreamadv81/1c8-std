# Форматирование даты, числа, Булево: требования по локализации (#std763)

**Суть.** Форматную строку, видимую пользователю, оборачивают `НСтр`; для дат берут `ДЛФ`, для
передачи между системами — сериализацию.

**Обязательно**
- Форматная строка в свойствах метаданных и форм локализуется всегда, как синоним (1).
- Применять `НСтр` к форматной строке: у даты — при произвольном формате (`ДФ`) и представлении
  пустой даты (`ДП`); у числа — при нечисловом представлении нуля (`ЧН`), шаблоне
  форматирования (`ЧФ`), переопределённом разделителе дробной части (`ЧРД`); у `Булево` —
  всегда (1.1, 1.2, 1.3).
- Представления полей в отчётах на СКД переопределять по тем же правилам, что в коде (3).
- Значение в машиночитаемом виде сериализовать, а не локализовать; локализацию дат использовать
  всегда, когда возможно, где нецелесообразно — допустимо отказаться (4).

**Не надо**
- Задавать формат даты явно там, где подходит локальный (`ДЛФ`): порядок частей и разделители в
  странах разные (1.1).
- Переопределять локализацию данных по умолчанию — формат операционной системы; у `Формат`
  избегать параметра «L=» (1.4).

**Совет**
- В полях ввода форм и полях отчётов на СКД тоже локальный формат даты; другой допустим, если
  локальный не подходит по сути задачи (2).
- Сериализация — `XMLСтрока`, десериализация — `XMLЗначение` или
  `ОписаниеТипов.ПривестиЗначение` (4).
- Свои форматы передачи: дату сериализовать в ISO «ГГГГ-ММ-ДДTЧЧ:ММ:ССZ» (4.1).
- Число и `Булево` сериализовать `XMLСтрока`, а не `Строка` или `Формат` (4.2, 4.3).
