# Строковые константные выражения в коде: требования по локализации (#std764)

**Суть.** Строковые константы с внутренними идентификаторами не локализуют, а представления
объектов и типов в алгоритмах не используют.

**Обязательно**
- Строковые идентификаторы, не выводимые пользователям, именовать по правилам именования
  идентификаторов переменных встроенного языка (`"ОтгрузкаКлиентам"`); то же в текстах запросов и
  выражениях СКД (1).
- Предопределённое значение на клиенте получать по строковому имени из конфигуратора:
  `ПредопределенноеЗначение("Перечисление.ЮридическоеФизическоеЛицо.ЮридическоеЛицо")` (2.1).

**Не надо**
- Применять `НСтр` к строковым константам с внутренними идентификаторами: они не локализуются (1).
- Использовать в алгоритмах представления объектов и типов: они только для вывода пользователю,
  меняются с языком и ломают локализацию и интеграцию (2).

**Совет**
- Строковые константы возвращать функциями: упрощает отладку и рефакторинг и снимает
  неоднозначность, когда идентификатор выглядит строкой для пользователя без `НСтр` (1).
