# Элементы форм: требования по локализации (#std765)

**Суть.** В формах локализуют представления значений и заголовки таблиц, групп, колонок, а
незначащее убирают.

**Обязательно**
- Для всех таблиц и групп на формах указывать заголовки, а не нужен показ — снимать
  `ОтображатьЗаголовок`: иначе в «Изменить форму» видны заголовки из имён элементов,
  непереводимые (2, рис.).
- Уменьшать количество незначащей информации: удалять бессмысленные
  подсказки у групп форм (их видно при изменении формы) и очищать заголовки реквизитов, не
  размещённых элементами управления (3, 3.1, 3.2, рис.).
- Задавать заголовок колонкам динамического списка из комбинации колонок или со своим псевдонимом;
  имя колонки — всегда, оно видно в «Изменить форму...» (4, рис.).
- В полях со списками выбора всегда ставить `РежимВыбораИзСписка` = `Истина`: выводится
  локализуемое представление, а не значение (5).

**Не надо**
- Присваивать реквизитам элементов формы строковые значения, не прошедшие локализацию (1).
- Опираться на автогенерированный заголовок колонки по имени или псевдониму (4).

**Совет**
- Для них брать списки значений с локализуемым представлением (`СписокВыбора`,
  колонка «Представление») либо перечисления, если значения хранятся в базе (1, рис.).
- Заголовки расставлять обработкой автоформатирования кода и локализации из статьи (2).
