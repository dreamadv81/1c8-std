# 1c8-std — стандарты разработки 1С:Предприятия 8 для Claude Code

Навык для [Claude Code](https://claude.com/claude-code), который даёт модели «Систему стандартов и методик разработки
конфигураций для платформы 1С:Предприятие 8» ([its.1c.ru/db/v8std](https://its.1c.ru/db/v8std)): имена, структура и описание
модулей, запросы и их оптимизация, транзакции и блокировки, клиент-серверное взаимодействие, обработчики событий, права и
безопасность, метаданные, обмен данными, библиотеки, локализация, управляемые и обычные формы, интерфейс. Модель пользуется
навыком, когда пишет, правит или проверяет код и метаданные 8.x и ей нужно знать, чего требует стандарт.

**Полного текста статей в репозитории нет**: права на стандарты принадлежат фирме «1С». В навыке — выжимки: правила
пересказаны своими словами с номерами пунктов статей, дословных цитат немного (около 2,5 % текста), и стоят они в кавычках.
Статью целиком модель читает на its.1c.ru, ссылку печатает сам навык.

## Как устроен навык

Сведения разложены на три уровня, чтобы не тратить контекст модели на то, что ей сейчас не нужно.

- **Свод** в `SKILL.md` — около сорока правил, которые касаются любого модуля: имена, оформление модуля, запросы, транзакции,
  клиент и сервер, обработчики событий, безопасность. Модель видит их сразу, как только подключает навык.
- **Выжимки** в `digest/` — по одной на каждую из 319 статей: суть статьи и правила в трёх группах «Обязательно», «Не надо» и
  «Совет». У каждого правила в скобках номер пункта статьи или пометка, что правило взято из текста, рисунка или таблицы.
- **Статья** — полный текст на its.1c.ru: `std8.py show <номер> --full` печатает ссылку на неё.

У статей про интерфейсы 8.2 и про обычное приложение выжимка начинается с пометки применимости, чтобы модель не переносила
эти правила на управляемые формы в интерфейсе «Такси».

## Возможности

- `std8.py show 783` — выжимка статьи по номеру, `--full` — ссылка на статью на its.1c.ru.
- `std8.py find транзакц запрос` — выжимки, в которых есть все слова (слово ищется по началу); `--in` сужает поиск до раздела.
- `std8.py list` — разделы оглавления с числом статей; `list "Оптимизация запросов"` — статьи раздела с применимостью:
  управляемое, мобильное, обычное приложение.

## Требования

**Python 3.9 или новее.** Достаточно стандартной библиотеки, сторонние пакеты не нужны.

## Установка

Скопируйте каталог `1c8-std` в каталог навыков Claude Code: в `~/.claude/skills/` — чтобы навык был доступен во всех проектах,
или в `<проект>/.claude/skills/` — только в одном проекте.

```bash
cp -R 1c8-std ~/.claude/skills/                    # macOS и Linux
```

```powershell
# Windows, PowerShell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
Copy-Item -Recurse 1c8-std "$env:USERPROFILE\.claude\skills\"
```

Claude Code подключает навык сам: когда модель пишет или проверяет код 1С 8.x, она прочитает свод в `SKILL.md`, а нужную статью
найдёт поиском. Команды можно запускать и вручную; в Windows — через `py -3`.

## Быстрый старт

```bash
S=~/.claude/skills/1c8-std/std8.py

python3 $S show 783                 # выжимка «Транзакции: правила использования»
python3 $S show 783 --full          # ссылка на статью на its.1c.ru
python3 $S find транзакц запрос     # где говорится и о транзакциях, и о запросах
python3 $S find --in "Соглашения" имя
python3 $S list                     # разделы
python3 $S list "Оптимизация запросов"
```

Коды возврата: 0 — нашлось, 1 — ничего не нашлось, 2 — неверный вызов.

## Ограничения

- Выжимки соответствуют стандартам на июль 2026 года — это последний месяц журнала «Новые и измененные разделы» (статья 788).
  Что поменялось в стандартах позже, в выжимках нет.
- Рисунков и таблицы сочетаний клавиш в навыке нет: правило, показанное в статье рисунком, записано словами с пометкой «(рис.)».
- Выжимки написаны моделью и сверены с оригиналом моделью-рецензентом. Если формулировка важна, решает текст статьи.
- Типовых конфигураций и БСП в навыке нет, только стандарты их использования. Справочника по встроенному языку тоже нет — он в
  навыке [1c8-doc](https://github.com/dreamadv81/1c8-doc).

## Как разрабатывался навык

Навык написан моделями Claude в среде [Claude Code](https://claude.com/claude-code) под руководством человека с 17 по
19 сентября 2026 года: 89 коммитов. Сначала все 319 статей перевели в Markdown, затем для каждой написали выжимку и проверили
её по статье. Получилось 2 453 правила; по числу слов выжимки в два с половиной раза короче статей.

Каждую выжимку проверяют автоматические сторожа: выжимка есть у каждой статьи, её отпечаток сходится с текстом статьи, каждый
названный номер пункта в статье существует, группы правил идут в порядке «Обязательно — Не надо — Совет» и не пусты, суть
статьи не пуста, а `SKILL.md` не больше 9 КБ. Всего у навыка и сборки книги 148 тестов. В комплект они не входят: они
проверяют выжимки по полному тексту статей, а его в репозитории нет.
